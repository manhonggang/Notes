## 玩法架构

### 两阶段循环

| 阶段 | 类型 | 内容 |
|------|------|------|
| 筹备/升级 | 策略层 | 查看预订表、建造/升级房间、放置公共区域、规划楼层布局、预算管理 |
| 运营 | 操作层 | 安排入住、处理突发事件、清洁、送餐、维修、安抚 |
| 结算 | 反馈层 | 满意度评分 → 收入 → 回筹备阶段 |

### 核心设计哲学：属性制，非物种制

- ❌ 冰窖房 = 企鹅专用（死板，缺乏扩展性）
- ✅ 每个房间有 6 维环境属性，动物有偏好区间，匹配产生满意度

### 房间属性系统

每个房间 6 维属性，范围 -2 ~ +2：

| 属性 | -2 | -1 | 0 | +1 | +2 |
|------|-----|-----|---|-----|-----|
| 🌡️ 温度 | 寒冷 | 凉爽 | 常温 | 温暖 | 炎热 |
| 💧 湿度 | 干燥 | 偏干 | 适中 | 偏湿 | 潮湿 |
| ☀️ 光照 | 全暗 | 昏暗 | 柔和 | 明亮 | 暴晒 |
| 🔊 噪音 | 死寂 | 安静 | 一般 | 热闹 | 嘈杂 |
| 🏔️ 高度 | 地下 | 低层 | 地面 | 高层 | 顶层 |
| 📐 空间 | 紧凑 | 偏小 | 标准 | 宽敞 | 超大 |

### 低端房间

属性固定，便宜，靠组合搭配解决问题：

| 房间 | 温度 | 湿度 | 光照 | 噪音 | 高度 | 空间 | 特点 |
|------|------|------|------|------|------|------|------|
| 🛏️ 标准间 | 0 | 0 | 0 | 0 | 0 | 0 | 全中性，万金油但不突出 |
| 🏠 小阁楼 | +1 | -1 | +1 | -1 | +2 | -1 | 温暖干燥安静的高处小空间 |
| 🕳️ 地下室 | -1 | +1 | -1 | -1 | -2 | +1 | 凉爽潮湿昏暗的安静大空间 |
| 🌻 阳光房 | +1 | -1 | +2 | 0 | +1 | -1 | 温暖干燥明亮的略高处 |
| 🌳 树荫房 | -1 | 0 | -1 | -1 | +1 | 0 | 凉爽安静的自然光高层 |
| 🏡 花园小屋 | 0 | +1 | +1 | 0 | 0 | 0 | 适中偏湿明亮的平地标准间 |

### 高端房间

可调属性或特殊能力，贵但灵活：

| 房间 | 基础属性 | 特殊能力 |
|------|----------|---------|
| 🌟 景观套房 | 全 0（可自选 +1 到一个属性） | 视野加成，高处动物额外满意度 |
| 🌡️ 恒温套房 | 温度固定 0 | 抵消邻接温度影响 |
| 🔇 静音套房 | 噪音固定 -2 | 完全隔音 |
| 💧 水景套房 | 湿度 +1, 温度 -1 | 水栖动物满意度翻倍 |
| 🌿 花园套房 | 光照 +1, 湿度 +1 | 自然系动物满意度 +50% |
| 🌙 穹顶套房 | 光照可调（-2~+2 自由切换） | 唯一可自由切换光照的房间 |

### 公共区域

不直接住人，影响相邻房间属性 + 提供社交满意度加成：

| 公共区域 | 邻接效果 | 社交加成 | 运营操作 |
|----------|---------|---------|---------|
| 🏊 泳池 | 湿度 +1, 噪音 +1 | 水獭、青蛙、鸭子、企鹅 ↑ | 定期清洁 |
| ♨️ 温泉 | 温度 +1, 湿度 +1 | 猴子、水豚、熊 ↑ | 冬季加成翻倍 |
| 🔭 观景台 | 光照 +1（仅上方房间） | 鸟、松鼠、猫 ↑ | 望远镜维护 |
| 🍽️ 餐厅 | 噪音 +1 | 所有动物微幅 ↑ | 需要厨师，可升级菜单 |
| 📚 图书馆 | 噪音 -1（压制邻接噪音） | 猫头鹰、猫、兔子 ↑ | 保持安静 |
| 🌺 花园 | 光照 +1, 湿度 +1 | 蝴蝶、蜜蜂、兔子 ↑ | 季节性花卉更换 |
| 🎵 音乐厅 | 噪音 +2 | 鹦鹉、猴子、鸣禽 ↑ | 可调音量 |
| 🧖 水疗中心 | 无邻接效果 | 所有动物微幅 ↑ | 高端设施，维护费高 |

### 策略三角

```
低端房间缓冲（多花一间房）→ 高端房间硬解（花钱买免疫）→ 公共区域分流（不占房间但有其他效果）
```

## 动物物种 × 属性偏好

### 偏好机制

动物的偏好是**舒适区间**，落在区间内 = 满分，区间外逐步递减。例如猫的温度 [+1, +2] → 温度 +1 完美，0 还行，-1 不太舒服，-2 要退房。

## 运营阶段操作

| 操作 | 触发条件 | 操作方式 | 失败后果 |
|------|---------|---------|---------|
| 🛎️ 安排入住 | 客人到达 | 拖动客人到房间 | 安排错误→不满 |
| 🔄 换房 | 客人投诉/不满 | 拖动到新房间 | 持续不满→退房 |
| 🧹 清洁 | 房间脏了/退房后 | 点击清洁按钮 | 新客人无法入住 |
| 🍽️ 送餐 | 餐厅有订单 | 点击送餐 | 客人饥饿→不满 |
| 🔧 维修 | 设施损坏 | 拖动维修工 | 影响相邻房间 |
| 🎁 安抚 | 特殊事件 | 选择安抚方式 | 负面评价 |

### 结算公式

```
满意度 = 房间属性匹配度 × 邻接兼容度 × 公共区域加成 × 服务响应度
收入 = 基础房价 × 满意度倍率 + 小费（满意度超过阈值）
```

## 策略空间

1. **分组策略**：把偏好重叠的动物分到同一层（猫+兔子+仓鼠 = 温暖干燥层）
2. **缓冲策略**：低端房间过渡 / 高端房间硬解 / 公共区域分流
3. **季节策略**：不同季节客人组合不同，没有永远最优的布局
4. **经济策略**：低端回本快但运营累 vs 高端回本慢但省心 vs 公共区不直接赚钱但拉升整体满意度

## 美术方向

### 风格定位

- **「动物们的布达佩斯大饭店」**：韦斯·安德森式的对称美学 × 欧洲黄金时代大酒店 × 日本审美的克制留白
- 数字手绘（Digital Hand-painted），干净的线条 + 轻微的笔触质感
- 情绪关键词：体面、宁静、有仪式感、淡雅、professional but warm
- 不是：粗糙木屋、玻璃幕墙现代酒店、金碧辉煌土豪风、迪士尼城堡

### 风格锚点

**布达佩斯大饭店（Wes Anderson）**：
- 粉色系但不是甜腻——褪色的、有年代感的粉
- 极致的对称构图 → 天然带来「体面」「专业」的气质
- 装饰克制——有石膏线、黄铜吊灯，但不堆砌
- 色彩经过「褪色处理」——像旧明信片，饱和度偏低

**欧洲黄金时代大酒店（Belle Époque / Art Deco，1920-1930s）**：
- 高挑大堂、旋转楼梯、水晶吊灯
- 材质：白色大理石地面、深色木质前台、哑光黄铜灯具
- 不是土豪金，是哑光的、擦亮的黄铜——「淡然的高级感」
- 对称、秩序、仪式感：前台正中，楼梯左右分叉

**日本老铺的克制美学（渋い shibui）**：
- 装饰藏在细节里（木纹肌理、铜器包浆）
- 色彩是「灰调」——每种颜色都降了饱和度
- 留白本身就是高级感

### 色彩体系

| 用途 | 颜色 | 感觉 |
|------|------|------|
| 建筑外墙 | 淡粉色 (#E8D5D0) ~ 暖象牙白 (#F5F0E8) | 褪色的优雅 |
| 屋顶/檐口 | 灰紫色 (#B8A9B4) ~ 深灰蓝 | 克制 |
| 大堂墙面 | 奶油白 + 下半截深木护墙板 | 老派体面 |
| 前台/家具 | 深胡桃木 (#5C3A21) | 厚重 |
| 金属件 | 哑光黄铜 (#C4A46C) | 不闪的贵气 |
| 软装点缀 | 鼠尾草绿、灰粉、淡蓝灰 | 安静的点缀 |
| 灯光 | 暖琥珀色 (#E8C56D) | 温暖但不炽热 |
| 地板 | 奶油色+鼠尾草绿棋盘格大理石 | 秩序感 |

### 角色比例

3-4 头身，圆润轮廓，保持动物形态（非迪士尼拟人），能做出拟人动作。

员工穿制服：礼宾猫头鹰（紫色小制服）、清洁浣熊、厨师熊——强化「酒店服务」的 fantasy。

### 玩家角色

酒店经营者/经理（人类或动物），穿得体但不死板的制服，有职业感而非民宿老板感。

### UI 风格方向

- 老派体面感：烫金纹理、皮革质感、大理石底纹
- 标题字体：优雅衬线体（Didot / Bodoni 方向）
- 正文：清爽无衬线
- 按钮/卡片：哑光黄铜边框 + 奶油色底

## 差异化总结

| 维度 | 动物森友会 | 妙妙酒店 |
|------|-----------|---------|
| 核心 fantasy | 我是岛民，这是我的生活 | 我是酒店老板，这是我的事业 |
| 时间感 | 与现实同步，慢 | 一局 5-10 分钟，快节奏 |
| 动物关系 | 邻居/朋友，无利益关系 | 客人/服务者，有满意度指标 |
| 空间设计 | 全岛自由布置 | 酒店房间组合策略 |
| 核心乐趣 | 收集、装饰、社交 | 解谜式安排、效率优化 |
