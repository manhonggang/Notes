# 价值网络于游戏获客的应用

> 为什么有些游戏能在TapTap这张网中生存，而有些游戏只能在买量网络中生存。

[[价值网络]] [[创新者的窘境]] [[魔法数字：游戏收入驱动模式的诊断框架]]

---

## 一、两张网：拓扑结构不同，资源流向不同

用克里斯坦森的"价值网络"框架来看，TapTap和买量网络不是同一张网的两条边，而是**两张完全不同的拓扑图**——节点不同，连线不同，"谁决定钱往哪儿流"的规则也不同。

### TapTap网

| 节点 | 连线（资源流） |
|------|--------------|
| 玩家社区 | 口碑流——评分、长评、攻略、二创 |
| 游戏开发者 | 零分成协议——开发者保留100%收入 |
| TapTap平台 | 流量分发——编辑推荐、社区热议、评分排序 |
| KOL/内容创作者 | 内容传播——实况、评测、攻略搬运 |

关键网络效应：一个玩家写了好评 → 被更多潜在玩家看到 → 新玩家进入后也写好评 → 社区热度上升 → 平台算法推荐权重提升 → 更多玩家看到。连线是"口碑"和"社区参与"，**回路一旦启动就自持运转**。

### 买量网

| 节点 | 连线（资源流） |
|------|--------------|
| 广告平台（穿山甲、优量汇等） | 现金流——按CPM/CPC/CPA结算 |
| 买量团队/投放优化师 | 数据流——ROI、转化率、LTV/CAC |
| 渠道（抖音、快手、头条等） | 注意力流——信息流广告位 |
| 游戏产品 | 用户流——安装→激活→付费 |

关键网络效应：投入广告费 → 买到用户 → 用户付费 → 用付费收入继续买量 → 买更多用户。连线是**现金**而非口碑。**一旦现金注入停止，回路立刻断裂。**

### 两张网的核心差异：定价权在谁手里

TapTap网中的游戏拥有**体验定价权**——因为口碑好，玩家愿意为体验本身付费（买断、月卡、战令），定价权在游戏自己。买量网中的游戏只有**流量定价权**——用买量获取用户，用付费深度收割用户，定价权在广告平台而非游戏本身。体验定价权意味着设计自由度：你可以把付费点放在"好玩"上，而不是放在"转化率"上。

## 二、互锁陷阱：被买量网困住不是因为做错了

克里斯坦森价值网络的核心洞见：**企业被它的价值网络困住，不是因为它做错了什么，而是因为它做对了它的网络要求它做的事。**

一个游戏一旦进入买量网，它的整个成本结构、绩效指标和决策逻辑都会被这张网锁定：

1. **赢利公式被锁定**：LTV > CAC是唯一的生存公式。所有决策围绕"如何让单个用户的生命周期价值超过获取成本"，迫使游戏设计向短期变现效率倾斜——首充礼包、七日签到付费转化、滚服收割。

2. **性能指标被锁定**：买量网考核的核心指标是**次日留存、3日留存、7日付费转化率**。这和[[魔法数字：游戏收入驱动模式的诊断框架]]中分析的"渗透率驱动型"完全吻合——收入与新进强相关，买量停止则收入骤降。

3. **互锁关系形成陷阱**：
   - 买量团队需要稳定素材产出 → 游戏必须频繁更新活动/付费点来支撑素材
   - 高CAC要求高ARPU → 付费设计必须深坑化
   - 深坑化赶走免费用户 → DAU下降 → 买量依赖更深
   - 买量依赖加深 → 成本结构进一步固化

> 互锁陷阱的推论：买量网中的游戏必然走向"付费与参与度解耦"——付费不等于更好玩，只等于"比免费用户更强"（[[越付费，越好玩]]的逻辑不成立，付费是纵向堆叠而非横向质变）。这又进一步恶化口碑，加深买量依赖。不是失误，而是理性选择的必然结果。

TapTap网的约束逻辑完全不同：零分成释放了设计空间，不必追求首日付费转化；考核指标是评分和社区活跃度；互锁关系形成正循环（好评分→社区传播→更多玩家→更多UGC→编辑推荐→更高曝光→开发者有动力更新→游戏更好）。

## 三、分水岭：免费用户的生态价值

不是所有游戏都能选择自己的网络。**决定游戏"能活在哪张网"的结构性分水岭，是免费用户在获客系统中扮演什么角色。**

- TapTap网中，免费用户**本身就是获客手段**——他们写攻略、发二创、参与讨论，这些行为直接驱动新用户进入
- 买量网中，免费用户只是"付费用户的体验"，对获客没有结构性贡献

这意味着：**一个游戏如果免费用户没有生态价值，它的TapTap飞轮就物理性地无法启动**——不是口碑不够好的问题，是系统缺少燃料。

免费用户能产生生态价值，需要游戏满足以下条件（这些条件是递进的，而非并列的）：

| 递进层次 | 条件 | 解释 |
|---------|------|------|
| 1. 体验可传播 | 玩法有"可讲述性"，玩家愿意主动分享 | 《月圆之夜》——卡组构筑有策略深度，攻略和讨论有传播价值 |
| 2. 深度参与产生付费 | 付费与参与度耦合，而非与曝光度耦合 | 《帕斯卡契约》——买了游戏就想打通，付费点在体验本身 |
| 3. 口碑飞轮自持 | 老玩家带新玩家，且效应可自持 | 《香肠派对》——TapTap 8.6分，社区讨论活跃，自然增长 |
| 4. 长线运营信用 | 玩家相信游戏不会"跑路" | TapTap评分体系本身就是信用机制 |

> 对应[[魔法数字：游戏收入驱动模式的诊断框架]]：这些游戏的魔法数字应该是收入与ACU高度相关——**规模驱动型**。增长飞轮是"产品做好→人多→更好玩→更多人→更多收入→更多资源投入产品"，而不是"买量→获客→付费→再买量"。

## 四、跳网是非对称的：从TapTap可以"爬"，反向几乎不可能

克里斯坦森最深刻的洞见：**颠覆者不是在旧网里击败在位者，而是从另一张网起步，再沿着性能曲线"爬"进旧网。**

```
买量网中的在位者（大DAU+高买量成本）
         ↑
    性能曲线爬升
         ↑
TapTap网中的新进入者（小DAU+高口碑+零买量）
```

一个游戏从TapTap网起步，评分高、社区活跃、口碑好；随着品质提升，开始吸引买量网中的用户；但它**不需要买量**也能活下去，因为增长飞轮是自我强化的。

反向跳网几乎不可能，原因有三层：

1. **成本结构已固化**：团队规模、投放预算、运营节奏都是为买量模式设计的，无法承受"停买量等口碑"的过渡期
2. **产品结构已锁定**：深坑化、短平快的设计改不了——改了就流失现有付费用户
3. **信用已破产**：买量游戏的TapTap评分往往很低，这种负面资产不可逆——"改改"无法消除

> 这正是克里斯坦森说的非对称问题：向上流动（进入买量网的高端用户群）容易，向下流动（进入TapTap网的口碑生态）反而难。TapTap网对买量网来说就是"最低层"——用户付费深度低、ARPU低、短期回收慢，但正是这个"最低层"孕育了自持增长的可能性。[[创新者的窘境#^168618]]

所以跳网的可行路径只有一条：**做一个新游戏**。克里斯坦森的结论——设立独立机构而非在旧机构内部转型（[[创新者的窘境]]第24-29点）——在这里同样成立。

## 五、诊断方法：魔法数字是价值网络归属的检测器

| 魔法数字类型 | 对应网络 | 增长飞轮 |
|-------------|---------|---------|
| 渗透率驱动型 | 买量网 | 买量→获客→付费→再买量（需要持续注入外部资源） |
| 混合型 | 买量网为主，TapTap网有少量贡献 | 买量+运营节奏共同驱动 |
| 规模驱动型/ACU驱动型 | TapTap网 | 产品做好→人多→更好玩→更多人→更多收入（自我强化） |

**核心诊断逻辑**：如果一个游戏的收入与ACU高度相关（规模驱动型），那它有可能活在TapTap网；如果收入与渗透率或新进高度相关（渗透率驱动型），那它几乎只能活在买量网。你的游戏魔法数字是什么，它就已经告诉你你被哪张网捕获了。

免费用户生态价值→魔法数字类型→价值网络归属，这是一条因果链：**产品结构决定了收入驱动模式，收入驱动模式决定了你被哪张网捕获。** 获客策略的选择不是在两个渠道之间做选择，而是在产品结构层面就已被决定了。

## 六、自检清单

| 问题 | 如果"是" | 如果"否" |
|------|---------|---------|
| 玩家会主动向朋友推荐这个游戏吗？ | TapTap网候选 | 买量网依赖 |
| 游戏中有"可讲述的策略"吗？（非纯数值碾压） | TapTap网候选 | 买量网依赖 |
| 免费玩家对付费玩家有生态价值吗？ | TapTap网可行 | 买量网锁定 |
| 付费是否让体验产生了质变？（[[越付费，越好玩]]） | TapTap网可行 | 买量网锁定 |
| 7日付费转化率对收入的影响远大于ACU吗？ | 买量网特征 | TapTap网特征 |
| 停止买量一周后DAU是否腰斩？ | 买量网锁定 | 有TapTap网可能性 |

## 七、开放问题

1. **原神属于哪张网？** 原神同时在买量网和TapTap网中——它有极高的买量投入，但同时也拥有极强的口碑飞轮。这是否意味着存在"双网共存"的模式？还是说原神的口碑飞轮已经足够自持，买量只是加速器而非必需品？

2. **TapTap网的天花板**：TapTap的用户规模有限（相比抖音/快手），这是否意味着TapTap网中的游戏永远无法达到买量网中游戏的DAU上限？还是说口碑飞轮可以突破平台边界（如Steam、B站）？

3. **买量网的终局**：随着CAC持续上升，买量网中的游戏利润率会持续下降。是否存在一个"买量网崩溃"的临界点？到那时，TapTap网中的游戏是否会自然接管？

4. **中间地带**：是否存在"买量启动→口碑接棒"的过渡路径？即先用买量获取种子用户，等产品品质被验证后转向口碑驱动？[[用知识体系拆解《剑与远征》的成功逻辑]]中描述的莉莉丝发行策略（KOL+核心群体自来水+焦土策略）是否就是这个路径？
