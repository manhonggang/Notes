# 文档空行处理流程

## 概述
本方法用于批量处理Markdown文档中多余的空行，保留合理的段落间距，使文档更加紧凑易读。经过实践验证，可有效处理微信读书导出的笔记文档。

## 核心Perl脚本

### 1. 单文件处理脚本
```bash
perl -ne 'if (/\S/) { print; $prev_empty = 0 } else { print unless $prev_empty; $prev_empty = 1 }' "文件名.md" > "文件名.new" && mv "文件名.new" "文件名.md"
```

### 2. 脚本原理说明
- `/\S/`：匹配任何非空白字符
- `$prev_empty`：标记前一行是否为空行
- 逻辑：
  - 如果当前行**有内容**：打印，重置标记
  - 如果当前行**为空行**：仅当前一行非空时才打印，设置标记
- 效果：将连续多个空行压缩为单个空行

## 使用示例

### 示例1：处理单个文件
```bash
# 备份
cp "史蒂夫·乔布斯传.md" "史蒂夫·乔布斯传.md.backup"

# 处理
perl -ne 'if (/\S/) { print; $prev_empty = 0 } else { print unless $prev_empty; $prev_empty = 1 }' "史蒂夫·乔布斯传.md" > "史蒂夫·乔布斯传.new" && mv "史蒂夫·乔布斯传.new" "史蒂夫·乔布斯传.md"

# 验证
wc -l "史蒂夫·乔布斯传.md" "史蒂夫·乔布斯传.md.backup"
```

### 示例2：批量处理多个文件
```bash
# 创建处理脚本
cat > process_empty_lines.sh << 'EOF'
#!/bin/bash
for file in *.md; do
  if [ "$file" != "*.md" ]; then
    echo "处理: $file"
    cp "$file" "$file.backup"
    perl -ne 'if (/\S/) { print; $prev_empty = 0 } else { print unless $prev_empty; $prev_empty = 1 }' "$file" > "$file.new" && mv "$file.new" "$file"
  fi
done
EOF

# 执行脚本
chmod +x process_empty_lines.sh
./process_empty_lines.sh
```

## 恢复方法

如果处理结果不满意，可以恢复原文件：

```bash
# 恢复单个文件
mv "文件名.md.backup" "文件名.md"

# 批量恢复所有备份文件
for file in *.backup; do
  original="${file%.backup}"
  if [ -f "$file" ]; then
    mv "$file" "$original"
    echo "已恢复: $original"
  fi
done
```

## 注意事项

### 1. 字符编码
- 中文字符路径：建议在子shell中处理
- 特殊字符：使用引号包裹文件名
- 示例：
  ```bash
  (cd "资料及书影音笔记" && perl -ne '...' "文件名.md" > "文件名.new" && mv "文件名.new" "文件名.md")
  ```

### 2. 格式保留
- 本方法会**保留**：
  - 段落之间的单个空行
  - 所有非空白内容
  - Markdown标记（###、-、> 等）
- 本方法会**移除**：
  - 连续的两个及以上空行（压缩为1个）

### 3. 安全性
- **务必先备份**：处理前自动创建备份文件
- **验证结果**：处理前后对比文件行数和格式
- **测试**：可先在小文件上测试，确认效果后再批量处理

### 4. 处理效果统计

## 常见问题

### Q1: 为什么使用Perl而不是sed/awk？
- Perl处理多行和中文编码更稳定
- sed在BSD/macOS与GNU Linux行为不一致
- 该脚本已在实际环境中验证可靠性

### Q2: 是否会影响Markdown格式？
- 不会影响Markdown语法（#、*、`等）
- 保留必要的空行分隔
- 压缩多余空行，提高可读性

### Q3: 能否处理子文件夹？
可以，结合find命令：
```bash
find . -name "*.md" -type f -exec bash -c '
  for file; do
    echo "处理: $file"
    cp "$file" "$file.backup"
    perl -ne "if (/\S/) { print; \$prev_empty = 0 } else { print unless \$prev_empty; \$prev_empty = 1 }" "$file" > "$file.new" && mv "$file.new" "$file"
  done
' bash {} +
```

## 高级技巧

### 1. 创建alias（长期使用）
```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
alias compress-empty-lines='perl -ne '\''if (/\S/) { print; $prev_empty = 0 } else { print unless $prev_empty; $prev_empty = 1 }'\'''

# 使用
compress-empty-lines input.md > output.md
```

### 2. 预览空行分布
```bash
# 查看连续空行最多的段落
perl -ne 'if (/\S/) { if ($empty_count > $max_empty) { $max_empty = $empty_count } $empty_count = 0 } else { $empty_count++ } END { print "最大连续空行: $max_empty\n" }' "文件名.md"
```

### 3. 仅处理特定章节
```bash
# 使用awk提取特定章节后处理
awk '/^###.*章节标题/,/^###/ || /^###.*章节标题/ {print}' "文件名.md" | perl -ne '...' > "章节处理.md"
```
