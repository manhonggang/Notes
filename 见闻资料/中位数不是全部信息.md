> 原文：[[The Median Isn't the Message]]

一篇极具说服力的文章，帮助我以"健康"的视角看待医生、研究人员、其他医学专业人士——以及媒体——抛出的那些统计数据。毫不夸张地说，这篇文章对我的生活和健康产生了巨大的影响。

**中位数不是全部信息**
**Stephen Jay Gould 著**

**最近，我的生活以最私人的方式**与马克·吐温的两句名言交汇了。一句我留到文末再说。另一句（有时被归于迪斯累利），列举了三种谎言，每一种都比前一种更恶劣——谎言，该死的谎言，和统计数据。

**来看一个用数字扭曲事实的典型例子**——这个案例与我接下来的故事密切相关。统计学承认"平均值"（或称集中趋势）有不同的衡量方式。均值是我们日常理解的整体平均——把所有项目加起来再除以人数（万圣节五个孩子总共收到的100根糖果，在公正的世界里每人分到20根）。中位数则是另一种集中趋势的度量，即处于正中间的那一点。如果我按身高把五个孩子排成一列，位于中间的那个孩子比两个高、比两个矮（而那两个孩子可能拿不到平均份额的糖果）。执政的政客可以自豪地说："我国公民的年均收入是15,000美元。"反对党领袖可以反驳："但有一半公民年收入不到10,000美元。"两人都没说错，但谁也没有引用不带偏见的客观数据。前者引用的是均值，后者引用的是中位数。（在这种情形下，均值高于中位数，因为一个百万富翁就能压过数百个穷人来抬高均值；但在计算中位数时，他只能抵消一个乞丐。）

**更深一层的问题**——那种对统计学的普遍不信任甚至蔑视——更加令人不安。许多人错误地将心灵与头脑、情感与理智割裂开来。在某些当代思潮中（以刻板印象中南加州的态度为推波助澜者），情感被奉为更"真实"的东西，是行动的唯一正当基础——感觉好就去做——而理智则被贬为过时精英主义的枷锁。在这种荒谬的二元对立中，统计学往往沦为敌人的象征。正如希莱尔·贝洛克所写："统计学是定量方法的胜利，而定量方法是贫瘠与死亡的胜利。"

**这是一个关于统计学的个人故事**——正确解读的统计学，是深具滋养力、赋予生命的力量。它向贬低理智的倾向宣战，方式是讲述一个小故事，关于那些枯燥的学术科学知识的实际用处。心灵与头脑是同一个身体、同一个人格的两个焦点。

**1982年7月，我得知自己患上了腹部间皮瘤**，一种罕见而凶险的癌症，通常与接触石棉有关。手术苏醒后，我向我的医生兼化疗师问了第一个问题："关于间皮瘤，最好的专业文献是什么？"她带着一丝委婉回答道（这是她唯一一次没有直说），医学文献中没有什么真正值得读的。

**当然，想让一个知识分子远离文献**，大约和劝人类——所有灵长类中最好色的那个——守贞一样有效。我一能下床走路，就直奔哈佛康特威医学图书馆，在计算机书目检索系统中输入了"间皮瘤"。一小时后，我被腹部间皮瘤的最新文献包围，这才发现——心里猛地一沉——医生为何给出那样善意的建议。文献再清楚不过了：间皮瘤无法治愈，发现后中位生存期仅八个月。我呆坐了大约十五分钟，然后笑了笑，自言自语道：原来如此，难怪他们什么都不给我看。好在，我的脑子又开始转了。

**如果说一知半解可能误事**，我碰到的便是一个经典案例。态度在抗癌中显然至关重要。我们尚不知原因（从我这老派的唯物主义视角看，我猜测心理状态会反馈作用于免疫系统），但在年龄、阶层、健康状况、社会经济地位相当的同类癌症患者中，那些态度积极、求生意志强烈、有明确生活目标、全力以赴抗争、主动配合治疗而非被动接受医生一切安排的人，往往活得更久。几个月后，我请教了我的个人科学导师、诺贝尔免疫学奖得主 Peter Medawar 爵士：战胜癌症的最佳处方是什么？"乐观的性格，"他答道。所幸（因为人不可能在短时间内有目的地重塑自我），我恰好就是这么一种脾性——性情平和，充满信心。

**于是人道医生面临的两难**便在于：既然态度如此关键，如此阴暗的结论是否还应公之于众？尤其考虑到很少有人具备足够的统计学素养来正确理解这些话的真正含义？凭借多年来对巴哈马陆生蜗牛小规模进化的定量研究经验，我掌握了这项专业知识——而我深信，它在我拯救自己生命的过程中发挥了重大作用。培根的格言说得对：知识就是力量。

**问题可以简述如下**："中位生存期八个月"用大白话说究竟意味着什么？我猜，大多数未经统计学训练的人会把这句话理解为"我大概率活不过八个月"——而这恰恰是必须避免的结论，因为它并不正确，而且态度的影响又如此之大。

**我当然没有欣喜若狂**，但也没有按那种大白话来理解这句话。我的专业训练让我对"八个月中位生存期"产生了不同的看法。这一点微妙而深刻——因为它体现了我所在的演化生物学和自然史领域独有的思维方式。

**我们至今仍背负着**柏拉图传统的历史包袱——那种追寻明确本质和清晰边界的传统。（于是我们总想找到毫无歧义的"生命的起点"或"死亡的定义"，尽管自然常常以不可还原的连续体呈现于我们面前。）这种柏拉图传统强调清晰的区分和分离的永恒实体，导致我们对统计集中趋势的理解恰恰是错误的——与我们这个充满变异、渐变和连续体的真实世界中应有的理解完全相反。简言之，我们把均值和中位数视为坚硬的"实在"，而把使它们得以计算的变异看作对某个隐藏本质的一组暂时的、不完美的度量。如果中位数就是实在，围绕中位数的变异不过是计算它的手段，那么"我大概率活不过八个月"似乎就可以算作合理的解读。

**但所有演化生物学家都知道**，变异本身才是自然唯一不可还原的本质。变异才是坚硬的实在，而非计算集中趋势的一组不完美度量。均值和中位数才是抽象。因此，我以截然不同的方式审视间皮瘤的统计数据——这不仅仅因为我是个天生看甜甜圈而非看甜甜圈洞的乐观主义者，更根本的原因是，我知道变异本身才是实在。我必须把自己置于变异之中。

**当我得知八个月的中位数时**，我的第一反应是理智上的：好，一半人会活得更久；那我有多少机会成为那一半？我紧张而急切地读了一个小时，如释重负地得出结论：机会很大。每一项有利于延长寿命的特征我都具备：我年轻；我的病发现得相对较早；我将接受全国最好的治疗；我有活下去的理由；我懂得如何正确解读数据而不会绝望。

**另一个技术细节**随后又给了我更多安慰。我立刻意识到，围绕八个月中位数的变异分布几乎必然是统计学家所说的"右偏"。（在对称分布中，集中趋势左侧的变异轮廓是右侧的镜像。在偏态分布中，集中趋势某一侧的变异被拉长——向左拉长则称左偏，向右拉长则称右偏。）变异分布必定是右偏的，我推理道。毕竟，分布的左侧有一个不可逾越的下界零（因为间皮瘤只能在死亡时或死亡前被确诊）。因此，分布的下半部（左半部）空间有限——它只能压缩在零到八个月之间。但上半部（右半部）却可以延伸很多年，即便最终没有人能幸存。分布必定是右偏的，而我需要知道那条延伸的尾巴有多长——因为我已经断定，自己各种有利条件使我极有可能身处曲线的那一部分。

**分布果然呈强烈的右偏**，有一条（虽然很小的）长尾，从中位数的八个月一直延伸了好几年。我没有理由认为自己不能处于那条小尾巴上，于是我长长地舒了一口气。专业知识帮了忙。我正确地读懂了图表。我提出了正确的问题并找到了答案。在那种境况下，我获得了所有可能的礼物中最珍贵的那一个——充裕的时间。我不必立即停下一切，遵从以赛亚对希西家的训诫——理好你的家，因为你必死，不能活了。我还有时间去思考、去规划、去战斗。

**关于统计分布，还有最后一点**。它们只适用于特定条件——在此例中，即在常规治疗方式下间皮瘤的生存情况。如果条件改变，分布也可能随之改变。我被纳入了一项实验性治疗方案，如果运气持续，我将成为新分布中的第一批——这个新分布中位数更高，右尾一直延伸到高龄自然死亡。

**在我看来，如今有一种风气**——把接受死亡视为内在尊严的体现，这多少有些过于时髦了。我当然赞同《传道书》中传道者的话：生有时，死有时——当我的生命之线走到尽头，我希望能平静地以自己的方式面对终局。然而在大多数情况下，我更倾向于一种尚武的看法：死亡是终极之敌——而对那些怒斥光明消逝的人，我毫无非议。

**战斗的利剑有很多**，没有哪一把比幽默更有效。我的死讯在苏格兰的一次同事会议上被宣布，我差点享受到一种绝妙的快感——读到由我最好的朋友之一撰写的我的讣告（这家伙起了疑心去核实了；他也是统计学家，没料到我会出现在右尾那么远的地方）。尽管如此，这件事还是给了我确诊后第一次开怀大笑。想想看，我差点能重复马克·吐温最著名的那句话：**关于我死亡的报道被大大夸大了**。


## 解释

好，用1000个人来想。

### 中位数8个月 = 什么意思？

把1000人按生存时间从短到长排成一列，**第500个人**活了8个月。也就是说：

- 前500人：活不到8个月
- 后500人：活过8个月

### 关键：左右两半的"空间"不对称

**前500人（左半）**：生存时间最短可能接近0个月，最长8个月。这500人挤在 **0→8个月** 这段区间里，只有8个月的宽度。

**后500人（右半）**：生存时间从8个月起步，往上能走多远？——没有硬限制。可以活10个月、20个月、5年……

### 如果是对称的呢？

对称意味着右半和左半"镜像"。左半挤在8个月的宽度（0→8），右半也只占8个月的宽度（8→16）。那分布就是：

```
人数
 │ ████
 │ ██████
 │ ████████
 │ ██████████
 │ ████████████
 │ ██████████
 │ ████████
 │ ██████
 │ ████
 └──────────────────→ 生存月数
 0      8     16
```

对称、均匀，没有人活过16个月。

**但这要求一个前提：生存时间有一个硬上界16个月。** 没有任何物理法则规定间皮瘤患者最多活16个月。所以右尾不会被16个月截断——总有一些人因为发现早、体质好、治疗得当而活20个月、40个月、60个月。

而左尾呢？**0是一个硬下界**——没有人能活不到0个月以下，这是物理法则。

### 所以实际分布是这样的：

```
人数
 │ ████
 │ ██████
 │ ████████
 │ ██████████
 │ ████████████
 │ ██████████
 │ ████████
 │ ████████
 │ ██████
 │ ████
 │ ███
 │ ██
 │ █
 │ █
 └────────────────────────────→ 生存月数
 0      8        20   30   40
```

左半被0封住，挤得密；右半没有封顶，尾巴可以拖得很长。这就是右偏。
