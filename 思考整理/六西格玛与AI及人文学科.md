## 六西格玛（Six Sigma / 6σ）

六西格玛是一套以数据驱动、追求近乎零缺陷的**质量管理方法论**，由摩托罗拉在 1986 年提出，后被通用电气（GE）的杰克·韦尔奇发扬光大。

**"西格玛"（σ）** 是统计学中的标准差，用来衡量过程的变异程度：

| 西格玛水平 | 缺陷率（每百万机会 DPMO） | 良品率 |
|-----------|------------------------|--------|
| 1σ | 690,000 | 31% |
| 2σ | 308,000 | 69.2% |
| 3σ | 66,800 | 93.3% |
| 4σ | 6,210 | 99.38% |
| 5σ | 233 | 99.977% |
| **6σ** | **3.4** | **99.99966%** |

> 达到 6σ 意味着每 100 万次机会中只有 3.4 个缺陷，近乎完美。

### 核心方法论：DMAIC

| 阶段 | 含义 | 关键活动 |
|------|------|---------|
| **D**efine | 定义 | 明确问题、项目范围、客户需求（VOC） |
| **M**easure | 测量 | 收集数据，建立基线，验证测量系统（MSA） |
| **A**nalyze | 分析 | 找出根本原因（鱼骨图、FMEA、假设检验） |
| **I**mprove | 改进 | 设计方案、试点验证、消除根因 |
| **C**ontrol | 控制 | 建立控制计划（SPC、控制图），固化成果 |

### 关键工具

- **统计过程控制（SPC）**：用控制图监控过程稳定性
- **FMEA（失效模式与影响分析）**：事前预防潜在失效
- **鱼骨图 / 5-Why**：根因分析
- **假设检验 / 回归分析**：统计验证因果关系
- **DOE（实验设计）**：优化参数组合

### 角色体系（带级制）

```
冠军(Champion) → 黑带大师(MBB) → 黑带(BB) → 绿带(GB) → 黄带(YB)
```

### 与其他方法论的关系

- **精益（Lean）**：消除浪费、提升流速 → 二者结合形成「精益六西格玛」
- **TQM（全面质量管理）**：六西格玛的前身和理念基础
- **PDCA / PDSA**：戴明环，更通用的持续改进循环

## AI 与六西格玛

### AI 是六西格玛的超级加速器

| DMAIC 阶段 | 传统做法 | AI 增强后 |
|-----------|---------|----------|
| **D**efine | 人工访谈、问卷调查识别 CTQ | NLP 自动分析客户反馈、评论，提取真实需求 |
| **M**easure | 人工抽样、手工测量 | 传感器 + IoT 全量实时采集，测量系统自动校准 |
| **A**nalyze | 鱼骨图、假设检验（靠经验猜测方向） | 机器学习自动发现非线性关系、隐藏模式、多变量交互 |
| **I**mprove | DOE 实验设计（成本高、周期长） | 数字孪生 + 强化学习，在虚拟环境中试错优化 |
| **C**ontrol | SPC 控制图，人工监控 | AI 异常检测，预测性报警，自动调整参数 |

本质变化：从「事后分析」变成「实时预测」，从「抽样推断」变成「全量计算」。

### AI 本身"不六西格玛"——一个反讽

AI（尤其是生成式 AI）本身恰恰是**高变异系统**：

- 六西格玛要求过程**稳定、可重复**，输出变异可控
- LLM 的输出本质上是**概率采样**，同一个 prompt 两次结果不同
- "幻觉"就是缺陷，但消除幻觉不是靠减少变异，而是靠改变模型架构
- 3.4 DPMO 对生成式 AI 来说目前是天方夜谭

> **AI 和六西格玛的关系是双向的：AI 是六西格玛最强的工具，同时 AI 本身也是最需要六西格玛的对象。**

## 人文学科：从六西格玛"之外"到"之内"

### 为什么人文学科传统上在六西格玛之外？

六西格玛有一个隐含前提：**存在可定义、可测量的"质量特性"（CTQ）**。人文学科恰恰抵抗这个前提：

| 六西格玛需要 | 人文学科提供 |
|------------|------------|
| 可重复的过程 | 每次都是独一无二的创作 |
| 可量化的缺陷标准 | 意义是多元的、模糊的 |
| 客户需求可明确（VOC） | 读者解读因人而异 |
| 减少变异 = 提高质量 | 变异（风格、视角）= 价值本身 |

> 你无法定义一首诗的"缺陷率"。李商隐的《无题》暧昧不明，按六西格玛的标准这是"规格不清的缺陷"，但这恰恰是它的美学价值。**人文学科的核心价值——模糊性、多义性、主观性——天然与六西格玛的测量逻辑对立。**

### 为什么 AI 让它们变成了"之内"？

关键转折点：**AI 把人文学科的内容生产变成了一个"过程"。**

**之前的模式（手艺人的单件生产）：**

```
人 → 阅读、思考、酝酿 → 写出一篇文章
```

每次生产都是独特的，每个产出都不可比。没有稳定的过程，就没有统计质量控制的对象。

**之后的模式（工厂的规模化生产）：**

```
Prompt → LLM 推理过程 → 生成文本
```

同一个模型、同一套参数、同一种推理机制，生产出成千上万篇文本。突然间：

- **过程稳定了**：Transformer 架构是确定的，参数是固定的
- **缺陷可定义了**：幻觉、偏见、逻辑断裂、事实错误——这些都是可度量的"缺陷"
- **质量可统计了**：准确率、一致性、安全性——这些就是 CTQ

> **AI 把人文学科的"内容"变成了"产品"，把"创作"变成了"制造"。一旦变成制造，六西格玛就进来了。**

### 具体表现

| 领域 | AI 化后的"六西格玛化" |
|------|---------------------|
| 写作 | RLHF 本质上就是对文本生成做质量控制——减少有害输出（缺陷） |
| 翻译 | BLEU 分数、COMET 分数——这就是翻译质量的"西格玛水平" |
| 历史分析 | 幻觉率可测量——引用的文献是否存在、年代是否准确 |
| 法律文书 | 条款的准确性、引用的正确性——每个错误都是一个缺陷 |
| 教育评估 | AI 批改作文的一致性——评分者间信度变成了模型稳定性 |

### 底层逻辑：测量能力的边界扩张

```
六西格玛的适用范围 = 可测量 + 有稳定过程

         AI 出现前                    AI 出现后
    ┌─────────────────┐      ┌──────────────────────────┐
    │  制造业           │      │  制造业                    │
    │  物流             │      │  物流                      │
    │  客服中心         │      │  客服中心                  │
    │  软件开发         │      │  软件开发                  │
    ├─────────────────┤      │  写作 ✨                   │
    │  写作            │      │  翻译 ✨                   │
    │  艺术            │      │  法律分析 ✨               │
    │  哲学            │      │  医学诊断 ✨               │
    │  音乐            │      │  音乐创作 ✨               │
    └─────────────────┘      │  编程 ✨                   │
      "之外"的世界             ├──────────────────────────┤
                              │  （还在之外：            │
                              │   纯粹的主体体验、        │
                              │   爱的意义、              │
                              │   存在的追问…）           │
                              └──────────────────────────┘
```

**AI 没有消灭"之外"，但大幅压缩了它的疆域。**

## 终极追问

当人文学科的内容可以被 AI 大规模、低缺陷地生产时，人文学科还剩什么？

剩下来的恰恰是真正"之外"的东西——**价值判断、存在体验、意义的赋予**。

AI 可以写出一篇逻辑严密、引证准确、毫无幻觉的哲学论文，但"为什么要关心这个问题"、"这个答案对我的人生意味着什么"——这些仍然在六西格玛的测量之外。
