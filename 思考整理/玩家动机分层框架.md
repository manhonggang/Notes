# 玩家动机分层框架

## 核心论点

玩家进入游戏的动机不是一个平面列表，而是一个**从外到内的分层结构**：外层是"什么吸引了我"（入口），中层是"什么让我留下来"（需求），内层是"什么让我成为我"（身份）。三层之间不是并列关系，而是递进关系——外层动机把人拉进门，中层需求让人站稳，内层身份让人离不开。

你直觉上把动机分为"题材、玩法、社交"三个入口，这三样恰好覆盖了入口层的三个主要方向。但入口只是开始——**真正决定玩家生命周期的不是入口，而是入口是否通向了中层需求和内层身份。**

```
入口层（什么吸引了我？）
├── 题材吸引 ──→ 身份共鸣
├── 玩法熟悉 ──→ 胜任预期
└── 社交牵引 ──→ 归属承诺
      │
      ▼
需求层（什么让我留下来？）── SDT 三需求
├── 胜任感 ──→ 我在变强
├── 自主性 ──→ 我在自选
└── 关联性 ──→ 我属于这里
      │
      ▼
身份层（什么让我成为我？）── Agency 建构层
├── 自我建构 ──→ 我在游戏里建造"理想的我"
└── 社会验证 ──→ 别人认可"这个我"
      │
      ▼
终极层（一切动机的底层）
└── 模式匹配 ──→ 人是台神奇的模式匹配机器
```

---

## 入口层：什么吸引了我

入口层回答"玩家为什么愿意跨过门槛"。你直觉上分的三类——题材、玩法、社交——恰好是入口层三个最强大的方向，但每一类背后都有更深的驱动力。

### 1. 题材吸引 → 身份共鸣

"三国这个题材我喜欢"——表面上是喜欢一个IP，深层是**身份共鸣**：三国的叙事、人物、价值观和我有某种共振。我不是在"选一个游戏"，我是在"选一个我愿意投入情感的世界"。

题材吸引的深层机制：
- **认知效率**：已有题材的心智模型，降低了入门的认知成本——我知道刘备是谁、赵云能打，不需要从零学起。这和 [[结构是认知引擎]] 的逻辑一致：题材是结构在最外层释放的认知余量
- **情感预载**：对题材的熟悉度在进入游戏前就预装了情感——看到关羽出场就不需要设计师再花力气建立好感，题材替你做了
- **身份投射**：选择一个题材，就是选择一个"我想成为谁"的预设——三国玩家想当谋士或猛将，二次元玩家想进入一个"被认真对待的幻想世界"

> [!tip] 题材是身份的入口
> 题材选择不是审美偏好，而是身份选择。玩家选三国而不是赛博朋克，不是因为"三国更好看"，而是因为"我想成为三国里的人"——这已经踏入了 Agency 的建构层。

### 2. 玩法熟悉 → 胜任预期

"这个玩法我熟悉，喜欢"——表面上是习惯，深层是**胜任预期**：我知道这类玩法的快乐模式，我预判自己能在这里获得胜任感。

玩法吸引的深层机制：
- **可预测的胜任感路径**：熟悉玩法 = 知道"变强"的路线图。RTS 老玩家看到新RTS，不是在评估"好不好玩"，而是在评估"我能不能在这里复现我曾有的掌控感"
- **迁移成本优势**：已有技能可以直接迁移，认知成本最低——又是 [[结构是认知引擎]] 的逻辑：熟悉玩法是结构在技能层释放的认知余量
- **模式匹配的已知快感**：你已知这类玩法能提供什么样的模式发现快感，你在寻求"再来一次"——[[人是台神奇的模式匹配机器]]

> [!warning] 玩法熟悉的陷阱
> 玩法熟悉是入口，但也是天花板。玩家因为熟悉而进入，也会因为"太熟悉"而离开——当模式匹配不再产出新模式时，快乐就消失了（[[游戏的节奏——傅里叶框架]] 中"规律性太高 = 没有新模式可发现 = 快乐消失"）。**玩法熟悉驱动进入，玩法创新驱动留存。**

### 3. 社交牵引 → 归属承诺

"大家都玩，我也试试"——表面上是随大流，深层是**归属承诺**：我所在群体的行为暗示了"加入=被接纳"。

社交吸引的深层机制：
- **关联性预装**：朋友在玩 = 我进入时就已经有了关联性的落脚点。不需要游戏本身来建立社交，社交在游戏外已经存在
- **FOMO（错失恐惧）**：群体行为制造的"不参与就落后"压力，本质上是关联性需求的反面——不参与 = 被排斥
- **社会身份建构**：大家都在玩的东西，参与本身就在建构"我是这个群体的人"——这又是 Agency 的建构层。在中文语境下尤其强大：[[见闻资料/agency 心理学]] 指出中文语境的 agency 是"别人怎么看我 → 我调整 → 我呈现"，社交牵引恰恰是这条路径的起点

> [!important] 中文语境下社交动机更强
> SDT 把自主性排在第一位，但 [[自我决定理论]] 中已经指出：中文语境下 agency 的核心驱动力不是自主性，而是关联性。这意味着在中国市场，社交牵引不只是一个入口，而是**最强大的入口**——征途数据中"交朋友"（14.38%）+"成为高手受人尊重"（11.07%）= 25.45%，已经超过"纯粹娱乐"（39.93%）的一半。如果把"受人尊重"也归入社交驱动（它是关联性+胜任感的组合），社交动机的权重会更大。

### 入口层缺失的两个方向

你的三个入口覆盖了题材（身份）、玩法（胜任）、社交（归属），但还有两个重要的入口方向：

- **逃避/解压**：我不是"被什么吸引"，而是"想离开什么"——工作压力、生活无聊、情绪需要出口。征途数据中"消遣时间"（14.66%）可能大量属于此类。逃避动机的深层是**自主性补偿**——现实中的自主性被剥夺（被工作/生活控制），游戏中寻求自主性的替代满足
- **叙事/沉浸**：我想进入一个故事，成为其中的人。这和题材吸引不同——题材是"世界"的吸引力，叙事是"经历"的吸引力。叙事沉浸的深层是**身份体验**：我不仅想"成为三国里的人"，我还想"经历一段只属于我的三国故事"

## 需求层：什么让我留下来 —— SDT 三需求

入口把人拉进门，但**停留需要需求被持续满足**。[[自我决定理论]] 提供了最系统的框架：胜任感、自主性、关联性。

### 胜任感：我在变强

**核心问题**：我能不能在这个游戏中感受到"我在成长"？

胜任感不是"已经很强"，而是"正在变强"——**最优挑战**（optimal challenge）是关键：太难→焦虑，太易→无聊，刚好→胜任感。这和 [[结构是认知引擎]] 中"可阅读的墙触发内部动机"完全对齐。

胜任感在游戏中的实现路径：
- **技能成长**：操作变精准、策略变深、理解变透——从直觉层到逻辑层（[[付费颗粒度与体验闭环]] 的弧线）
- **资源积累**：装备、等级、收集——数值增长的可见反馈
- **模式发现**：自己发现机制、找到Build——[[选择力学统一框架]] 中"取舍的正确判断力"被放大

> 关键洞察：胜任感需要**信息性反馈**而非**控制性反馈**。"你做得好"（信息性）增强胜任感，"你必须这样做"（控制性）同时破坏自主性。[[结构是认知引擎]] 中"结构让失败可诊断"就是信息性反馈——它告诉你"哪里出了问题"，而不是"你必须这样打"。

### 自主性：我在自选

**核心问题**：我的行为是出于自己的选择，还是被系统推着走？

自主性在游戏中的实现路径：
- **选择空间**：[[选择力学统一框架]] 的四维（横/纵/空间/时序）——选择维度越丰富，自主感越强
- **选择的代价可接受**：取舍存在但不惩罚——空间压力 > 数值丧失，因为前者是"我选择不带"而非"我被迫失去"
- **从 push 到 pull**：[[付费颗粒度与体验闭环]] 中付费从推力变为拉力——玩家"想完成玩法"而自愿付费，而非"不付费就落后"
- **意志不被投射**：[[好游戏是结构返还的，不是意志投射的]]——设计师的意图通过结构间接传递，而非直接命令

> [!warning] 自主性的脆弱平衡
> [[自我决定理论]] 已经指出："结构本身不一定是命令，关键在于玩家是否感受到自主。'结构释放认知余量→玩家下潜'模型隐含假设了结构不伤害自主性，但这并不自动成立——结构可以变成隐形命令。" 线性关卡、强制教学、每日任务——这些结构在释放认知余量的同时，可能正在压缩自主性。

### 关联性：我属于这里

**核心问题**：我在这个游戏中是否感到和他人有连接？

关联性在游戏中的实现比多数设计师意识到的更广：

| 层次 | 表现 | 例子 |
|------|------|------|
| **直接互动** | 和朋友一起玩 | 组队、公会、聊天 |
| **间接连接** | 感知他人的存在 | 排行榜、拍卖行、别人的建筑 |
| **归属感** | 属于某个群体 | "我是这个服的"、"我是这个公会的" |
| **社会验证** | 被他人认可 | "成为高手受人尊重"（征途 11.07%） |
| **文化参与** | 参与更大的对话 | 讨论攻略、看直播、参与社区 |

> 核心洞察：征途数据中"交朋友"只有 14.38%，但这严重低估了关联性的作用。"成为高手受人尊重"（11.07%）本质上是关联性+胜任感的组合——"受人尊重"不是胜任感的副产品，而是**关联性的验证机制**。如果把"受人尊重"也归入关联性，关联性驱动的动机占 25%+，是最大的单一需求。

### 三需求的交互效应

三需求不是独立运作的，它们之间有强大的交互效应：

- **胜任感 × 自主性 = 心流**：[[自我决定理论]] 指出"心流和胜任感高度重合"，但心流还需要自主性——只有当玩家在最优挑战中**自主选择**接受挑战时，心流才会产生。被迫的挑战只产生压力，不产生心流
- **胜任感 × 关联性 = 社会比较驱动**：排行榜、段位——"我比别人强"同时满足了胜任感和关联性（我在群体中的位置）
- **自主性 × 关联性 = 共同体**：和朋友一起做选择——"我们决定怎么打"，而非"系统让我打"或"我独自打"
- **三需求同时满足 = 内在动机爆发**：当玩家同时感到"我在变强（胜任感）、这是我选的（自主性）、我和伙伴一起（关联性）"时，动机从外在驱动完全转为内在驱动——[[自我决定理论]] 中动机连续体的最右端

## 身份层：什么让我成为我 —— Agency 建构层

[[自我决定理论]] 与 [[见闻资料/agency 心理学]] 中已经指出：SDT 停在了第二层（自主性），但人类不止于"自由地做选择"——人用自由来**建构自我**。这是 Agency 的第三层和第四层。

### 自我建构：我在游戏里建造"理想的我"

**核心问题**：我在游戏中是否在塑造一个我满意的自我形象？

身份建构是比需求层更深的驱动力。一个玩家可以持续数年玩同一款游戏，不是因为胜任感还在被满足（可能早就到顶了），而是因为他**正在用游戏中的资源（装备、称号、段位、社交地位）把自己打造成"他最满意的状态"**。

- 征途数据中"成为高手受人尊重"（11.07%）——SDT 把它拆成胜任感+关联性，但 Agency 会说这是**第三层**：玩家在用"高手"身份建构自己
- 二次元游戏玩家对角色的深度投入——不只是"好玩"，而是"这个角色代表了我对某种品质的认同"
- 女性向游戏中"被认可"的核心体验——[[女性游戏是Agency建构层的工程]] 指出女性向游戏的本质是满足关联性 + 支持建构层

### 社会验证：别人认可"这个我"

**核心问题**：我建构的自我形象是否被他人认可？

[[见闻资料/agency 心理学]] 中最有穿透力的观察：Agency 的验证需要"被看见"——就像那个姑娘需要营业员认可她的真包。游戏中的验证机制：

- **排行榜/段位**：不只是胜任感指标，更是"我是谁"的社会证明
- **公会/社区中的地位**：我在群体中的角色定义了"我是谁"
- **外观/称号/成就**：可展示的身份标记——"你看，我做到了这些"
- **被他人需要**：团队中"只有我能做这件事"——独一无二的社会价值

> [!important] 中文语境的身份建构更依赖社会验证
> [[自我决定理论]] 指出：西方 agency 是"我决定我是谁 → 我行动 → 我成为"，中文语境是"别人怎么看我 → 我调整 → 我呈现"。这意味着在中国市场，**社会验证不是身份建构的补充，而是身份建构的主要驱动力**。"成为高手"不是因为有内在追求，而是因为"在别人眼中我是高手"——关联性倒逼了身份建构。

## 终极层：一切动机的底层

[[玩游戏的动机有哪些？]] 中你已经提出：终极动机是**模式匹配**。[[人是台神奇的模式匹配机器]] 说人类通过模式识别获得快乐。

模式匹配作为终极动机的统一力：
- 胜任感 = 匹配到"我可以应对这个挑战"的模式
- 自主性 = 匹配到"这是我的选择"的模式
- 关联性 = 匹配到"我属于这里"的模式
- 身份建构 = 匹配到"这就是我"的模式

模式匹配框架解释了一个其他框架无法解释的现象：**为什么有些玩家在胜任感、自主性、关联性都不被满足的情况下仍然持续玩？** 因为他们还在寻找模式——即使体验是负面的，"找到规律"本身的快感仍然驱动着行为。这就是为什么"消遣时间"（征途 14.66%）不是一个空洞的动机——消遣的本质是低强度的模式匹配，人在无聊时仍然需要模式输入。

## 整合：动机分层与设计原则体系的映射

| 设计原则体系 | 对应的动机层 | 覆盖情况 |
|---|---|---|
| 以结构释放认知余量（2.1） | 胜任感 | ✅ 强覆盖 |
| 可阅读的墙触发内部动机（2.1） | 胜任感 | ✅ 强覆盖 |
| 意志不能投射（1.2/2.1） | 自主性 | ⚠️ 隐含但未明确 |
| 从 push 到 pull（4.2） | 自主性 | ⚠️ 隐含但未明确 |
| 让玩家发现而非被告知（3.1） | 自主性 + 胜任感 | ✅ 覆盖 |
| 用节奏引导模式识别（3.2） | 胜任感 + 模式匹配 | ✅ 覆盖 |
| 心流 | 胜任感 × 自主性 | ❌ 零专门笔记 |
| 社交/社区/关联性 | 关联性 | ❌ 几乎无专门讨论 |
| 动机内在化过程 | 动机连续体 | ❌ 完全空白 |
| 身份建构/Agency | Agency 第三四层 | ⚠️ 仅在[[女性游戏是Agency建构层的工程]]中讨论 |
| 题材/叙事/沉浸 | 身份共鸣 | ❌ 无专门讨论 |
| 逃避/解压 | 自主性补偿 | ❌ 无专门讨论 |

**缺口总结**：你的设计原则体系在"怎么做"上极其丰满（结构、体验、商业化），但在"为什么做"上有三个大洞：**关联性、身份建构、动机内在化**。这三个洞恰恰是解释"玩家为什么愿意进入你的结构"的关键。

## 动机连续体：从"被推着走"到"自己想走"

[[自我决定理论]] 中动机连续体是设计中最实用的工具之一——它告诉设计师：**好的设计不是消灭外在动机，而是帮助外在动机逐步内在化。**

| 阶段 | 玩家状态 | 游戏中的表现 | 设计目标 |
|------|---------|------------|---------|
| **无动机** | "不知道为什么在玩" | 纯粹消遣、机械操作 | 唤醒：提供第一个可发现的模式 |
| **外部调节** | "为了奖励而玩" | 每日签到、成就奖励 | 降低门槛，让玩家进入 |
| **内投调节** | "不玩会内疚/丢人" | 错过恐惧、社交压力 | ⚠️ 危险区——短期有效，长期有害 |
| **认同调节** | "理解为什么要做" | 认同游戏的策略深度 | 帮助玩家理解"为什么"，建立价值认同 |
| **整合调节** | "这游戏代表了我" | 游戏成为身份的一部分 | 提供身份建构空间 |
| **内在动机** | "就是觉得好玩" | 自主探索、模式发现 | 终极目标——这是3.1"让玩家发现"的直接对应 |

**关键设计原则**：内在化不是一步到位的，而是**逐层递进**的——和 [[结构是认知引擎]] 的递进逻辑完全一致。外在动机（签到奖励）→ 内投动机（不玩会落后）→ 认同动机（我理解这个游戏的深度）→ 内在动机（我就是觉得好玩）。设计师的工作是**让每一层到下一层的过渡尽可能自然**，而非试图跳过中间步骤。

> [!warning] 内投调节的危险
> "不肝会落后，太丢人了"——内投调节是游戏中最常见的留人手段，也是最危险的。它短期有效（玩家确实会回来），但长期消耗自主性——玩家从"我在自选"滑向"我被推着走"。征途数据中"成为高手受人尊重"如果被设计为"不成为高手就会被鄙视"，那它就从认同调节退化为内投调节——动机的质量完全不同。
