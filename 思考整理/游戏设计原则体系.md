# 游戏设计原则体系

## 核心结论

**游戏设计的底层逻辑可以归结为若干条相互独立的原则，它们分布在四个 MECE 层次上——元原则（设计者如何判断）、结构原则（系统如何搭建）、体验原则（玩家如何感受）、商业化原则（价值如何变现）。每一条原则都可以被独立验证、跨游戏迁移，它们共同构成了从"想清楚"到"做出来"到"卖出去"的完整设计链。**

这四个层次的关系是递进的：元原则决定你问什么问题，结构原则决定你用什么逻辑回答，体验原则决定回答以什么形式抵达玩家，商业化原则决定这个循环能否持续。

---

## 一、元原则——如何做设计判断

> 元原则不直接告诉你"怎么做"，而是告诉你"怎么想"。它们是其他一切原则的前提。

### 1.1 始于事实

一切设计和判断必须基于事实，而非观点或直觉。

从宏观到微观层层下钻：
- 什么市场我们能做？
- 我们有什么能力？
- 有哪些产品？它们的频域结构是什么？
- 我们独有的优势是什么？
- 系统能否服务目标？
- 如何定义成败？

Ray Dalio 的第一原则（拥抱现实、处理现实）和 Bertrand Russell 的理性主义在此汇合。这条原则的价值不在于"说得对"，而在于**它迫使你在每一次设计决策前先建立可验证的锚点**。做不到是常态，但不以此为目标，设计判断就失去了根基。

参见：[[怎样构思一个游戏系统【Part1】]]

### 1.2 设计师是侦察兵，而非造物主

> "A game designer is like a scout in the jungle — you try to find the best path through the jungle and minimize the time spent lost there." — Touko Tahkokallio (Supercell), GDC 2018

游戏藏在丛林深处。设计师的工作是**找到它**，而非从零建造它。

Jonathan Blow 表达了同一命题的另一面：游戏设计是"发现"而非"发明"。向系统提问，观察系统的回答，再基于回答追问。系统会返还给你一些你没有放入的东西——涌现出的模式、意外的交互、自然生长的复杂度。

这意味着设计师的核心能力不是"想出新点子"，而是**保持对眼前事物的开放态度**，然后识别出有价值的东西。

参见：[[Jonathan Blow 游戏设计的真如 Truth in Game Design (2011) - 知乎]]、[[构建基本要素来产生涌现性和节奏]]

### 1.3 玩法有保质期

一切都有保质期，包括玩法。今天觉得好玩的东西，明天可能就不觉得了。

"保质期"思维有两个推论：
- **抄一个玩法的频域时，必须意识到它的保质期可能已经过了。** 时域上看起来还流行的玩法，其频域结构可能已经临近衰减。频域框架告诉你"怎么抄才对"，保质期原则告诉你"什么时候不该抄"。
- **玩法是骨架，系统设计是在骨架上操作。** 有些系统能提供玩法和粘性，但不能替代核心玩法的成功。分析别的游戏时，要清楚区分这两层。

参见：[[怎样构思一个游戏系统【Part1】]]

### 1.4 学会取舍

任何系统都不可能没有代价。期望一个设计零副作用，几乎不可能。

魔兽世界选择副本（Instance）机制的代价是：
- 牺牲了野外无缝世界 Boss
- 牺牲了 PVP 掉落装备的刺激
- 牺牲了不打团本的独狼玩家

这个取舍的风险程度极大。大多数团队做不到这种决断——不是看不清楚，是不敢看清楚后下刀。

取舍原则是"始于事实"的直接推论：只有基于事实，才能清晰看到每一个选择的代价是什么；只有接受代价，才能做出真正有效的决策。

参见：[[怎样构思一个游戏系统【Part1】]]

## 二、结构原则——系统应该怎么搭

> 结构原则回答"规则与规则之间应该呈什么关系"。它们是频域设计的核心。

### 2.1 正交性

**正交 = 不相关。互相正交的东西之间不会相互影响。**

在游戏设计中，正交的规则维度让玩家可以独立地分解复杂决策。好的游戏通常有 2-5 个正交策略维度。如果规则不正交（比如新规则只是旧规则的数值放大），系统就退化为"线性堆积"，玩家会麻木。

**案例：围棋 vs 国际象棋。** 围棋只有一种棋子，一条核心规则（"气"），但规则在空间中的正交扩散产生了薄厚、模样、打入、侵消等无数时域表现。国际象棋有 6 种棋子、大量特殊规则，反而涌现复杂度更低——因为规则互相耦合，正交空间更小。

参见：[[正交]]、[[正交和链接是两种不同的设计方式]]、[[构建基本要素来产生涌现性和节奏]]

### 2.2 递进式设计

**高阶规则建立在低阶规则之上，新旧元素正交组合产生质变，而非线性替换。**

- **认知上**：玩家在已知之上理解未知，学习成本低
- **结构上**：每一层是下一层不可抽离的存在性前提（没有地格就没有城池的攻防意义）
- **体验上**：旧元素不被淘汰，而是被新语境重新诠释——未知最终照亮已知，产生"原来如此"的顿悟
- **结果上**：每新增一层正交规则，就新增一层涌现的可能

参见：[[递进式设计]]、[[构建基本要素来产生涌现性和节奏]]

### 2.3 涌现性

**规则组合后能产生规则本身未明确描述的行为。**

这是好规则的终极检验标准。如果规则组合后不能产生"你事先没放进去的东西"，那再多规则也只是加法，不是涌现。

案例：
- 康威生命游戏：3 条规则 → 滑翔机、振荡器、可运作的计算器
- 上帝也疯狂：传教士转化 + 战斗免疫转化 → 涌现"巡视营地"
- 万智牌：局部卡牌规则 → 玩家自行发现"引擎"组合
- Gearheads：12 种发条玩具的简单属性 → 18 个月迭代中发现"拳击蟑螂""永恒运动"等引擎

参见：[[构建基本要素来产生涌现性和节奏]]、[[Rules of Play（玩乐之道）-第14章：从涌现系统看游戏 - 知乎]]

### 2.4 半格结构 > 树形结构

**底层的连接结构决定了涌现的上限。**

半格结构（semilattice）比树形结构允许更多正交的连接路径。三战的地格本质上是一种半格结构——每个地格同时属于"空间连接网络"和"资源产出系统"，这种多重归属正是涌现的土壤。

参见：[[半格结构更适合战略游戏的地格设计]]、[[构建基本要素来产生涌现性和节奏]]

### 2.5 限制制造策略

**反直觉：限制不只不减少策略，反而创造策略。**

没有限制时，所有玩家会收敛到同一个最优解。限制（职业、颜色、种族、费用）强制把局部最优打包成"有明确强项和弱项的完整方案"，从而产生石头剪刀布式的策略多样性。

选择和选择之间需要有足够差异化的反馈，玩家才能清楚预判不同路径的结果。

参见：[[游戏策略设计框架]]

### 2.6 回环设计

**最厉害的武器藏在最初始的地方——终点重新照亮起点。**

黑暗之魂回到初始火炉、野球拳、摔跤吧爸爸的抱摔——结构上制造一个"原来它一直在那里"的顿悟时刻。递进式设计的完整闭环：不只是从已知走向未知，更是用未知反过来重新定义已知。

参见：[[回环设计]]

### 2.7 最小阻力原则——找那条"缝"

**好的结构降低认知成本。最高效的推进方式是找到结构里的"缝"——那个天然的弱点或空隙——顺着它切进去。**

庖丁解牛的高效不在于力气大，而在于找到了肌肉与骨头之间的缝隙。在产品设计中，"十倍好玩"就是游戏领域里最强的"缝"——它是一个在有限大脑里占据极致清晰、可预测且高正反馈的结构位置，一旦做到，用户的认知门槛自动降低。

参见：[[最小阻力原则和结构的关系]]

### 2.8 结构应该是有放大能力的

**设计结构不应只是"容纳"行为，而应该"放大"行为。**

一个喜欢社交的人上了 Facebook 会变得更社交——这是结构放大了人的天性。好的游戏结构同样如此：它不只是在规则层面支撑玩法，而是在结构层面让玩家的内在倾向被强化、被扩展。

参见：[[结构应该是有放大能力的]]、[[六个半的设计哲学 from Alex]]

## 三、体验原则——玩家怎么感受

> 体验原则回答"结构产生的结果如何抵达玩家"。结构正确不一定体验正确——这一层处理的是节奏、认知和情感。

### 3.1 对比而非堆积（High-Level Design）

**线性堆积难度（1→2 加难，2→3 再加难）基本是错的。**

单纯的刺激叠加让玩家麻木，麻木了就累，累了就留下"这游戏真糟糕"的印象。

正确做法：通过**对比**调整感知强度——
- 第一关：强烈刺激（新鲜感加分）
- 第二关：放缓刺激（避免疲劳）
- 第三关：与第一关等强（但已习惯，有减分）
- 第四关：比之前都强（加分）

设计分数可能只有 23，但体验分数能到 24——**通过对比实现"免费"的体验提升。**

这条原则不仅适用于关卡，也适用于战斗节奏、养成投放、商业化节奏。

参见：[[白金工作室制作人稻叶敦志：如何制作畅销全球的动作游戏？]]、[[游戏的节奏——傅里叶框架]]

### 3.2 不均匀优于均匀

**均匀的节奏让人想睡觉。不均匀提供反脆弱性。**

均匀之所以在某些情境下"好"，是因为它容易记忆——记住一部分就记住了全部。但容易记忆 ≠ 容易快乐。规律性太高意味着没有新东西可发现，快乐便消失了。

公路不全直线才好，吃饭不均匀反而可能更健康。从关卡设计到技能冷却到奖励投放，这一条都适用。

参见：[[不均匀比均匀好]]、[[游戏的节奏——傅里叶框架]]

### 3.3 新内容互斥原则

**每种新内容出现时，暂时压低其他内容模式的振幅，避免信息过载。**

- 新武器系统出现时，不要让注意力放在场景上
- 新宏观场景出现时，不引入新武器系统
- 每隔一段时间，把注意力切换到不同内容模式上，通过交错出现缓解疲劳

本质上是**在教学阶段需要信息聚焦，而非全面刺激**。Portal、Celeste、塞尔达的教程之所以不烦人，就是因为它们在教新东西时把其他维度的认知负载降到了最低。

参见：[[游戏的节奏——傅里叶框架]]

### 3.4 人是模式匹配机器

**快乐的本质是发现规律。**

人类天生是模式识别引擎——观察到现象，发现背后的模式，人就快乐。这一机制深植于基因，驱动了人类的认知进化。

对游戏设计的含义：**游戏应该制造可发现的有意义模式。** 不是把所有信息摊给玩家，而是让玩家自己"发现"规律。自己发现的东西，远比被告知的东西更有价值——这正是内部动机的来源。

由此衍生出节奏的本质：**节奏是便于人脑认知规律的信息传输频率。** 创作者使用节奏的目的，是让受众更容易追踪出规律、更容易发现模式、从而更容易快乐。

参见：[[人是台神奇的模式匹配机器]]、[[游戏的节奏——傅里叶框架]]

### 3.5 从场景出发设计，而非从能力出发

**动作游戏最常见的致命错误，是先设计玩家有什么能力。**

正确做法：先设计"玩家被丢进什么处境，他需要做什么来摆脱"——然后才设计能力来匹配。

设计师最重要的能力是视觉想象力：想象那个场景，然后想象那个让玩家脱身的、不可思议的能力。能力服务于场景，而非场景服务于能力。

参见：[[白金工作室制作人稻叶敦志：如何制作畅销全球的动作游戏？]]

## 四、信息原则——玩家如何感知系统

> 信息原则是结构原则和体验原则之间的桥梁。结构定义了"有什么信息"，信息原则定义"信息以什么方式抵达玩家，以及不抵达什么"。

### 4.1 信息展示的隐藏→半隐藏→公开谱系

游戏中的信息展示不是一个开关，而是一个连续谱：

- **完全隐藏**：战争迷雾、对手手牌——制造策略不确定性和探索动机
- **半隐藏**：塔科夫脚步声、Slay the Spire 意图图标——降低认知负载同时保留策略空间
- **完全公开**：LOL 分段血条、格斗游戏帧数表——提供精确决策依据

每一步有不同的策略效用。设计者的工作是**有意识地选择每个信息在谱系上的位置**，而非默认全部公开或全部隐藏。

参见：[[游戏中传递信息的艺术]]

### 4.2 信息差即玩法

**信息差本身就是一种玩法维度。**

塔科夫的本质是一个信息差游戏：耳机、热成像、地图知识、声音线索——全都是信息放大工具。处于信息劣势时，制造混乱而非保持沉默；处于信息优势时，保持沉默。信息优势和劣势之间的博弈，和枪法一样构成了游戏的核心体验。

参见：[[塔科夫总结]]

## 五、商业化原则——价值如何变现

> 商业化不是设计完再加的"外挂"，而是需要和核心玩法同一时间考虑的"内置"。结构决定了变现的上限，体验决定了变现的意愿。

### 5.1 横纵商业化

**两种基本的商业化维度：**

- **横向（宽度）**：收集不同元素，它们之间可以组合——多队伍、多角色、选择的广度
- **纵向（深度）**：深化单个元素——突破、命座、精炼

最成功的商业化混合两者：横向提供组合发现的动机，纵向提供付费的深度。要卖更多卡，要么增加宽度（更多场景需要更多角色），要么增加替代性付费路径（家园系统、图鉴战力）。

横纵混合的生命周期：早期横向为主（收集新角色），中期横向放缓纵向加速（玩家已有情感联结），晚期横向停滞纵向深挖+开辟新横向维度。

参见：[[横纵商业化思考]]、[[付费颗粒度与体验闭环]]

### 5.2 玩法拼图 → 数值拼图

**RPG 设计的双阶段结构：**

- **玩法拼图**（先）：技能组合、Build 协同——需要策略思考，吸引和留住玩家
- **数值拼图**（后）：属性优化——驱动付费

质变点在现代游戏中被前置（技能不再等到 30-40 级才解锁），因为玩家更没耐心了。玩法拼图负责"好玩"，数值拼图负责"变现"。两者的分界线需要仔细设计——如果数值拼图压倒了玩法拼图，玩家会感知到"pay to win"；如果玩法拼图没有数值拼图的支撑，游戏没有收入。

参见：[[魔灵召唤和暗黑套装的体系设计]]、[[付费颗粒度与体验闭环]]

### 5.3 质变点的横纵二象性

**最精致的商业化让质变点同时具备横向和纵向的双重感受：**

- **横向质变**：A + B → C（异质组合——"发现"）——新角色激活了已有角色的元素反应
- **纵向质变**：A → A'（同质衍生——"老朋友有了新面孔"）——命座让同一个角色获得新机制

纵向衍生有一个完整谱系：触发型 → 降费型 → 复制型 → 放大型 → 附加型 → 突变型。突变型极端处自然跨越到了横向领地——甘雨 C6 取消蓄力，等于重新定义了角色。

理想的质变点让玩家同时感受到"这东西有了新面孔"**和**"它让我的旧资产以新方式组合起来"——双重感受成倍放大了付费意愿。

参见：[[付费颗粒度与体验闭环]]

### 5.4 付费颗粒度与体验闭环

**所有商业化设计围绕三个层次：**

1. **颗粒度**：付费内容的"块大小"——角色 = 大块，宝石 = 小块。颗粒度决定了玩家"多久能感受到一次完整的付费体验"
2. **即时反馈**：双曲贴现决定了每次付费必须产生立即可感知的回报。抽到一张新支援卡如果当下收益不明显，普通玩家会放弃
3. **协同质变（二次曲线）**：积累到一定阈值后产生质变——2 件套 + 2 件套 > 4 件散件。二次曲线是连接"即时反馈"和"长期留存"的关键桥梁

参见：[[付费颗粒度与体验闭环]]

### 5.5 商业化是玩法的护城河

**即使核心设计出色，商业化策略的失误仍然可以毁掉一个游戏。**

The Bazaar 的核心设计备受好评，但商业模式反复横跳造成了严重伤害。一个游戏的商业化模型必须和核心体验匹配——不匹配会产生系统性问题，设计卓越也无法弥补。

参见：[[商业化才是玩法的护城河]]

| 原则 | 来源 | 核心含义 |
|------|------|---------|
| **别跟人性作对** | 万智牌 20 条经验 #1 | 不要试图改变玩家适应游戏，改变游戏适应玩家 |
| **共鸣很重要（借用常识）** | 万智牌 20 条经验 #3-4 | 植物大战僵尸用"植物=防守/僵尸=进攻"的常识消除教学负担 |
| **"听起来有意思" ≠ "真好玩"** | 万智牌 20 条经验 #5 | 智力刺激和情感刺激不同；情绪驱动决策远多于理性 |
| **枯萎技术的水平思考** | 横井军平 | 用成熟廉价的技术做创新应用；游戏的本质是互动而非技术 |
| **设计 = 结构化提效** | Alex Zhu（六个半设计哲学 #0） | 设计区别于艺术在于效用；设计通过结构化方案实现效用 |

## 附二：参考——来自外部剪藏的设计概念

以下概念来自剪藏内容 [[游戏策划、心得、与告别]]（作者 MelvinZhou，知乎），作为参考备用，并非本 vault 的原创原则。若未来有独立分析支撑，可以升级为正式原则。

| 概念 | 说明 |
|------|------|
| **合格单局三要素** | 熟练度（越玩越好）+ 策略性（同一问题至少 2 种解法）+ 清晰度（能观察、理解、学习）。三者中清晰度最常因"透明幻觉"（设计师以为玩家懂了）而失败 |
| **熵增单局 vs 熵减单局** | PVP = 熵增（双方从弱变强，终局最混乱紧张——"威胁赛跑"模型）。PVE = 熵减（敌人一开始最强，玩家解谜后确定性增加——"问题解决"模型）。好 PVE Boss 有三阶段：压缩→释放→重置。一个游戏难以同时做好两种 |
| **内部动机 > 外部奖励** | Deci 实验（1970）：外部奖励会摧毁内部动机。让玩家感到自己的**操作能力**在提升（而非数值在提升），是从内部动机驱动留存的关键 |

## 附三：原则之间的关系图谱

```
元原则（判断层）
    始于事实 ──→ 学会取舍
         │
    设计师是侦察兵 ──→ 玩法有保质期
         │
         ▼
结构原则（系统层）
    正交性 ──→ 递进式设计 ──→ 涌现性
    半格结构 ──→ 限制制造策略
    回环设计 ──→ 最小阻力原则 ──→ 结构放大能力
         │
         ▼
体验原则（感知层）
    对比而非堆积 ──→ 不均匀优于均匀
    新内容互斥 ──→ 从场景而非能力出发
    人是模式匹配机器
         │
         ▼
信息原则（桥接层）
    隐藏→半隐藏→公开谱系 ──→ 信息差即玩法
         │
         ▼
商业化原则（变现层）
    横纵商业化 ──→ 玩法拼图→数值拼图 ──→ 质变点横纵二象性
    付费颗粒度与体验闭环 ──→ 商业化是玩法的护城河
```

**关键交叉连接：**
- **正交性 + 递进式设计 = 涌现性的前提**（没有正交的递进只是堆积，没有递进的正交无法生长）
- **对比而非堆积 + 不均匀 + 新内容互斥 = 稻叶敦志 High-Level Design 的三条腿**
- **玩法拼图→数值拼图 + 横纵商业化 + 质变点二象性 = 同一个商业化逻辑在结构/体验/变现三个层面的展开**
- **最小阻力原则的"缝" = 结构原则在元原则层面的方法论表达**
- **人是模式匹配机器 = 体验原则的心理基础，支撑了对比、不均匀、新内容互斥等所有体验原则**
