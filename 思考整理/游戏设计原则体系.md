# 游戏设计原则体系

## 核心结论

**游戏设计可以被归结为十余条相互正交的*行动原则*，分布在四个递进层次上：元原则（怎么想）、结构原则（怎么搭）、体验原则（怎么传递）、商业化原则（怎么变现）。结构原则与体验原则之间，有一条显式的映射链——每条结构原则为玩家创造了一类特定的情感体验，体验原则则决定这些体验以什么节奏和形态抵达玩家。**

每条原则回答一个特定的设计问题，给出明确的行事准则。原则之下有衍生的设计技巧，原则之上有支撑它的知识和规律——本文在每条原则内对这三者做了清晰区分。

> 互补框架：[[选择力学统一框架]]——从"选择的结构"（横/纵/空间/时序+取舍约束）出发提供另一套正交分析工具。

> **这些原则服务于同一个信念：好游戏是结构返还的，不是意志投射的。**

## 一、元原则——如何做设计判断

> 元原则不直接告诉你"怎么做"，而是告诉你"怎么想"。它们是其他一切原则的前提。

### 1.1 始于事实

**原则：一切设计和判断必须基于事实，而非观点或直觉。设计师的工作是找到游戏，而非从零建造它——向系统提问，观察系统返还什么，这就是"以发现代替发明"。**

> "A game designer is like a scout in the jungle — you try to find the best path through the jungle and minimize the time spent lost there." — Touko Tahkokallio (Supercell), GDC 2018

技巧：从宏观到微观层层下钻——什么市场我们能做？→ 我们有什么能力？→ 有哪些产品？它们各自的优势和弱点是什么？→ 我们独有的优势是什么？→ 系统能否服务目标？→ 如何定义成败？

参见：[[怎样构思一个游戏系统【Part1】]]、[[Jonathan Blow 游戏设计的真如 Truth in Game Design (2011) - 知乎]]

### 1.2 找那条缝

**原则：最高效的推进方式是找到结构中的天然缝隙，顺着它切入，而非硬造结构。**

*依据：庖丁解牛的高效不在于力气大，而在于找到了肌肉与骨头之间的缝隙。结构本身暗示了最佳路径。详见[[最小阻力原则和结构的关系]]。*

> "缝"就是认知余量释放最大的点——结构在缝隙处对玩家大脑的阻力最小，认知成本最低、体验回报最高。2.1 在结构层给出了原理解释：[[以结构释放认知余量]]。

技巧——**"十倍好玩"就是游戏领域最强的缝**：它在玩家有限的认知资源中占据了一个极致清晰、可预测且高正反馈的结构位置。做到十倍好玩，意味着玩家用最少的注意力换取了最大的体验回报——这是认知效率的极限。一旦做到，用户认知门槛自动降低。

### 1.3 区分骨架与血肉

**原则：做设计判断时，先区分什么是骨架（核心玩法，决定好不好玩）和血肉（外围系统，提供粘性和变现）。两者判断标准不同——骨架看底层结构是否有效，血肉看是否适配用户习惯。**

*依据：系统再精良也救不了骨架朽坏的玩法。反过来，骨架优秀的游戏即使系统粗糙也能存活。*

技巧——**判断生命周期阶段**：抄一个玩法时，判断它处于上升期（越来越多玩家发现它的乐趣）还是衰退期（玩家已感到重复和疲劳）。在衰退期入场，意味着你还没上线就在和逐渐消退的兴趣赛跑。骨架的判断标准是底层结构（正交性、递进性、涌现潜力），而非表面热度。

参见：[[怎样构思一个游戏系统【Part1】]]

## 二、结构原则——系统应该怎么搭

> 结构原则回答"规则与规则之间应该呈什么关系"。本层的核心洞察：**结构之所以能驱动玩家深入，是因为它替大脑减负——每条原则从不同方向降低认知成本，释放出玩家沿弧线下潜的脑力。**

```
以结构释放认知余量（总纲）
  │
  ├── 正交 —— 分解耦合，逐维处理
  ├── 递进 —— 已知压缩，增量加载
  └── 限制 —— 缩小搜索空间
  │
  │  供需：释放的余量需要去处
  ▼
以涌现性为目标
  │
  │  部分重叠：公开侧减负，隐藏侧博弈
  ▼
将信息差设计为玩法
```

### 2.1 以结构释放认知余量

**原则：设计结构时，不只关注规则本身，而应关注结构是否在每一层替玩家承担了认知成本——省下的脑力，就是玩家沿 4.2 弧线下潜的入场券。**

*依据：人脑有限（[[最小阻力原则和结构的关系]]），玩家在每一层只能处理有限的信息。结构通过正交分解、递进构建、限制打包等方式，将上一层的复杂度压缩为可自动处理的"块"，释放出进入下一层的认知余量。参见：[[结构是认知引擎]]*

案例：Minecraft——不是方块"放大了建造天性"，而是方块结构把建造的认知成本吞掉了（统一的交互单元、可预测的物理规则、直观的视觉反馈）。玩家不需要学习复杂工具就能建造——**创造不是天性被放大，是认知门槛降低后自然涌现的行为。**

> 这条原则在元原则层的对应是 1.2"找那条缝"：1.2 告诉设计师去结构中找阻力最小的位置（方法），2.1 解释那个位置为什么阻力最小（原理）——结构在那里替玩家承担了最多的认知成本。好比走到岔路口：1.2 是"找那条被人踩得最亮的小径"，2.1 是"那条小径最亮，因为它坡度最缓、走路最不费力"。**找到缝，就是找到了结构释放认知余量的最优点。**

> 结构层其他原则各自与认知余量有不同关系——
> - **正交（2.2）、递进（2.3）、限制（2.4）** 是认知减负的直接手段：分别通过分解耦合、压缩已知、缩小搜索空间来释放认知余量
> - **涌现（2.5）** 是认知余量的去处：没有新可发现的模式，释放的脑力就没有出口
> - **信息差（2.6）** 的信息展示谱系中，公开侧降低认知负载，隐藏侧主动制造认知博弈

参见：[[结构是认知引擎]]、[[最小阻力原则和结构的关系]]、[[结构应该是有放大能力的]]

### 2.2 保持规则维度的正交

**原则：规则维度之间应该互相独立（正交），让玩家可以分解复杂决策，而非面对一团耦合的混沌。**

*依据：正交维度产生可分解的策略空间。规则不正交时，系统退化为线性堆积，玩家麻木。好的游戏通常有 2-5 个正交策略维度。*

案例：围棋只有一种棋子、一条核心规则（"气"），但规则在空间中的正交扩散产生了薄厚、模样、打入、侵消等无数对局表现。国际象棋有 6 种棋子、大量特殊规则，反而涌现复杂度更低——因为规则互相耦合，正交空间更小。

技巧——**多重归属优于单一归属**：允许多重归属的结构（即 Christopher Alexander 所说的半格结构/semilattice）允许节点在多个系统中同时扮演角色，为涌现提供更多连接路径。三战的地格同时属于"空间连接网络"和"资源产出系统"——这种多重归属产生涌现。参见：[[半格结构更适合战略游戏的地格设计]]

参见：[[正交]]、[[正交和链接是两种不同的设计方式]]

### 2.3 递进式构建

**原则：递进不止是从已知走向未知——真正的递进是让未知重新定义已知。高阶规则必须建立在低阶规则之上，新旧元素通过正交组合产生质变。**

*依据：*
- *结构上：每一层是下一层不可抽离的存在性前提——没有地格就没有城池的攻防意义*
- *体验上：旧元素不被淘汰而被新语境重新诠释时，未知最终照亮已知，产生"原来如此"的顿悟*
- *结果上：每新增一层正交规则，就新增一层涌现的可能*

技巧——**回环设计**：终点重新照亮起点。最厉害的武器藏在最初始的地方（黑暗之魂的初始火炉、野球拳）。递进的完整闭环不仅仅是"从已知走向未知"，而是"用未知重新定义已知"。参见：[[回环设计]]

参见：[[递进式设计]]、[[构建基本要素来产生涌现性和节奏]]

### 2.4 用限制创造策略

**原则：主动施加限制（职业、颜色、种族、费用），强制玩家在"有明确强项和弱项的方案包"之间做选择。**

*依据：限制将局部最优打包成石头剪刀布式的互克结构——每个方案都有明确针对它的天敌时，策略多样性自然产生。*

> 补充：不加限制时系统倾向于收敛到单一最优解——
> - **博弈论视角**：无约束系统中若存在一个严格占优的策略，理性玩家必然全选它；将决策空间切分为互相克制的片区（颜色轮、职业、种族），每个片区有各自的局部最优，全局收敛不再发生
> - **实操经验**：万智牌的颜色轮、MOBA 的 ban/pick、暗黑的职业分化——不加限制的系统（如早期开放技能树 MMO）几乎无一例外地收敛到版本答案。参见：[[游戏策略设计框架]]

技巧——**PVP 克制链 vs PVE 放大逻辑**：PVP 的克制是给玩家找到谜题的答案（看见对方阵容→针对性克制）；PVE 则更强调"某种放大"——通过系统放大玩家的特定行为。参见：[[PVE和PVP战斗的设计区别]]

参见：[[游戏策略设计框架]]

### 2.5 以涌现性为目标

**原则：设计规则时，以"规则组合能否产生我事先没放进去的行为"为检验标准。**

*依据：规则组合后产生未明确描述的行为，是好规则的标志。再多规则，如果不能涌现，也只是加法。*

案例：康威生命游戏——3 条规则 → 滑翔机、振荡器、可运作的计算器。

> 规律备忘：正交性 + 递进式设计 = 涌现性的前提条件。没有正交的递进只是堆积，没有递进的正交无法生长。这不是原则本身，而是原则之间的因果规律。

> 与 2.1 的关系：涌现不是认知减负手段，而是认知余量的**去处**——2.1 释放脑力，涌现提供"可被发现的新模式"让脑力有出口。没有涌现，释放的认知余量无处可去；没有认知余量，涌现的模式没人发现。

参见：[[构建基本要素来产生涌现性和节奏]]、[[Rules of Play（玩乐之道）-第14章：从涌现系统看游戏 - 知乎]]

### 2.6 将信息差设计为玩法

**原则：信息不对称不是一个需要消除的缺陷，而是一个可以主动设计的玩法维度。**

*依据：处于信息劣势→制造混乱；处于信息优势→保持沉默。信息和反信息的博弈本身构成了核心体验。*

案例：塔科夫——耳机、热成像、地图知识、声音线索全都是信息放大工具。信息博弈与枪法同等重要。

技巧——**信息展示谱系**：游戏中的信息展示是一个连续谱（完全隐藏→半隐藏→完全公开），不是开关。设计者的工作是有意识地选择每个信息在谱系上的位置，而非默认全公开或全隐藏。参见：[[游戏中传递信息的艺术]]

参见：[[塔科夫总结]]、[[游戏中传递信息的艺术]]

> 与 2.1 的关系：信息展示谱系同时包含两个方向——**公开信息降低决策负载**（与 2.1 同向），**隐藏信息制造认知博弈**（与 2.1 反向）。信息差的独特价值在于让"我知道你知道我不知道"的递归博弈本身成为玩法。

## 结构→体验：每条原则创造了什么感受

> 本节不是新的一层设计原则，而是结构原则与体验原则之间的**映射层**——显式回答"这条结构原则到底为玩家创造了什么情感体验"。

结构不是为自身而存在的。正交性、递进式、涌现性之所以是原则，不是因为它们让系统"优雅"，而是因为它们各自触发了一类特定的玩家感受。如果只记得"应该做正交设计"而忘了"正交创造的是可分解的掌控感"，设计就会退化为机械地套用规则，而非有意识地制造体验。

### 映射表

| 结构原则              | 系统层面做了什么              | 创造了什么体验                                               |
| ----------------- | --------------------- | ----------------------------------------------------- |
| **2.1 以结构释放认知余量**   | 结构逐层承担认知成本，释放脑力进入下一层 | **顺势下潜的自在感**——玩家感觉深度自然而然到来，不需要刻意努力；"不是我变强了，是我自然而然就走到这里了"    |
| **2.2 保持正交**      | 规则维度互相独立，决策可逐维分解      | **可分解的掌控感**——玩家能逐个维度理解和优化，获得"我搞懂了"的满足，而非面对一团耦合的混沌     |
| **2.3 递进式构建**     | 高阶规则建立在低阶之上，新旧正交组合    | **层层深入的顿悟**——旧知识被新语境重新照亮，玩家经历"原来它一直在那里"的认知升级          |
| **2.4 用限制创造策略**   | 强制在"有明确强项和弱项的方案包"之间选择 | **取舍的重量感**——每一次选择都有代价，正确决策的满足感被放弃的代价成倍放大；选择不再是轻飘飘的    |
| **2.5 以涌现性为目标**   | 规则组合产生设计者未显式放入的行为     | **发现意外之喜**——玩家觉得自己比设计师更聪明，找到了"漏洞"或"隐藏玩法"；这是内部动机的最强触发器 |
| **2.6 将信息差设计为玩法** | 信息不对称作为策略维度           | **认知博弈的紧张**——"我知道你知道我不知道……"的递归博弈本身成为快感来源，与操作技巧同等重要    |

### 创造体验 vs 传递体验

结构原则和体验原则在"体验"这件事上分工不同：

- **结构原则负责创造**：它决定玩家**能感受到什么**——通过设计规则和规则间的关系，搭建体验的**可能性空间**。正交性创造了"可分解的掌控感"这个可能性，但如果节奏设计失败（比如一下抛出十个正交维度），玩家实际感受到的是混乱而非掌控。
- **体验原则负责传递**：它决定体验**以什么节奏和形态抵达**玩家——通过控制信息流的频率、强度和对比，把结构创造的潜在体验**兑现**为玩家的实际感受。

同一个结构，配上不同的传递方式，会产生完全不同的情感质地。黑魂的战斗系统如果给更多检查点和更低死亡惩罚，同一套结构从"压迫感"变成"轻松挑战"。反过来，传递手段本身有时也能创造新体验——塔科夫的声音设计本质上是一种传递手段（脚步声的频率和响度），但它本身就是信息差体验的来源，模糊了创造和传递的边界。

因此，**创造和传递不是串行工序，而是需要协同设计的两个维度。**

## 三、体验原则——玩家怎么感受

> 体验原则回答"结构创造的可能性空间，以什么节奏和形态抵达玩家"。

### 3.1 让玩家发现，而非被告知

**原则：制造可发现的有意义模式——让玩家自己找到规律，而非把规律摊在面前。**

*依据：人类是模式匹配机器——观察到现象，发现背后的模式，人就快乐。自己发现的东西远比被告知的东西更有价值（内部动机 > 外部奖励，Deci, 1970）。*

**这条原则是体验层的根基。** 3.2"用节奏引导模式识别"是它的核心实现机制——节奏控制信息传输的频率和强度，让模式更容易被玩家追踪和发现。

技巧：
- **隐藏深度**：设计不被告知但可以被发现的机制——格斗游戏的帧数数据、Roguelike 的隐藏协同。玩家"自己发现的秘密"比"教程教给我的事实"有价值百倍
- **教学即探索**：不让教程成为独立的"说明阶段"，而是设计让玩家在操作中自然推导出机制的处境（Portal 的每个房间、塞尔达的每个神殿）
- **"啊哈"时刻的结构**：设置一个让玩家先困惑、再自行突破的时刻——困惑越深，突破时多巴胺越强

参见：[[人是台神奇的模式匹配机器]]

### 3.2 用节奏引导模式识别

**原则：通过控制信息传输的频率、强度和对比——即节奏——让玩家更容易追踪规律、发现模式。**

*依据：节奏是便于人脑认知规律的信息传输频率。游戏体验由多条不同频率的子波叠加而成——高潮来自多条子波同相叠加，低谷来自子波错相。傅里叶变换为此提供了拆解与重构的方法论。*

围绕这条原则的五个关键技巧：

| 技巧 | 怎么做 | 为什么有效 |
|------|--------|-----------|
| **不均匀优于均匀** | 避免均匀的节奏（如所有战斗都是"拉一波A过去"） | 规律性太高 = 没有新模式可发现 = 快乐消失 |
| **对比而非堆积** | 通过刺激强度的对比调整感知：强→缓→强→更强 | 对比放大感知强度，"免费"获得体验提升（设计23分→体验24分） |
| **新内容互斥** | 引入新系统时压低其他维度的振幅 | 教学阶段需要信息聚焦，避免认知过载 |
| **子波同相叠加** | 让战斗高潮+剧情高潮+系统里程碑同时触发 | 多领域峰值叠加时体验成倍放大 |
| **注意力调度** | 主动将玩家注意力在不同系统间切换，交替施放满足感 | 平行节奏制造"总有好玩的事在发生"的主观感受，避免单系统疲劳 |

> 关于子波拆解与叠加的完整方法论，参见：[[游戏的节奏——傅里叶框架]]

参见：[[不均匀比均匀好]]、[[白金工作室制作人稻叶敦志：如何制作畅销全球的动作游戏？]]、[[注意力的调度也是一种玩法]]

### 3.3 从场景出发，而非从能力出发

**原则：先设计"玩家被丢进什么处境、需要做什么来摆脱"，然后才设计能力来匹配处境。**

*依据：能力服务于场景，而非场景服务于能力。动作游戏最常见的致命错误就是先设计能力列表——这样设计出的能力没有存在理由，玩家感受不到"为什么需要这个能力"。*

> 延伸——**外部系统作为场景**：养成、收集、建造等外部系统同样是"场景"。玩家选择怎么花钱、怎么分配资源，本身是一种玩法。关键是让每个场景中的决策有意义（同一资源若只能用于一处且效能恒定，则退化为无效资源）。参见：[[把外部系统当成一种玩法]]

参见：[[白金工作室制作人稻叶敦志：如何制作畅销全球的动作游戏？]]

## 四、商业化原则——价值如何变现

> 商业化不是设计完再加的"外挂"，而是与核心玩法同时考虑的"内置"。结构决定变现上限，体验决定变现意愿。

### 4.1 横纵双向设计

**原则：同时运用横向（收集不同元素，组合发现）和纵向（深化单个元素，深度付费）两个商业化维度。**

技巧——**质变点横纵二象性**：让质变点同时具备横向感受（A+B→C，新角色激活已有资产）和纵向感受（A→A'，老朋友有了新面孔），双重感受成倍放大付费意愿。纵向衍生有一个完整谱系——从简单的触发型（满足条件自动生效）到极端的突变型（如甘雨 C6 取消蓄力，等于重新定义角色），突变型处自然跨越到了横向领地。详见[[付费颗粒度与体验闭环]]

> 与 4.2 的关系：质变点的触发往往由数值积累驱动——玩家在逻辑层持续投入（配装、洗练、阈值逼近），数值量变达到临界点后触发机制质变。4.2 的弧线描述了玩家"为什么愿意积累"，4.1 的质变点描述了"积累到了会怎样"。

参见：[[横纵商业化思考]]、[[付费颗粒度与体验闭环]]

### 4.2 让付费接续玩法的深度弧线

**原则：玩家对游戏的投入沿一条自然弧线加深——先直观的乐趣，再逻辑的钻研。付费不应压缩或跳过这条弧线，而应接续它：让每一次付费拓展而非压缩策略空间。**

*依据：玩法拼图在前建立吸引力（直觉层的快感），数值条件是同一玩法在更深层的展开（逻辑层的钻研）。玩家因为"想完成玩法"而自愿进入数值系统——变现是这条深度弧线的副产品，而非外挂。*

```

直觉层 → 玩法拼图建立吸引力（火队的快感）
  │
  ▼  撞墙："智力要到200"
逻辑层 → 数值条件引导钻研（配装、阈值、洗练）
  │
  │  数值量变 ──→ 机制质变（即 4.1 的质变点横纵二象性）
  │
  ▼  变现是弧线的副产品
衍生 → 玩家为了"完成玩法"自愿进入付费
```

技巧——**先直觉，后逻辑**：先在直觉层用玩法组合建立吸引力（技能协同、Build 多样性），再在逻辑层用数值条件引导钻研（阈值、配装、洗练）。两种体验嫁接在同一个系统上，数值不是变现的载体，是玩法深度的载体。参见：[[魔灵召唤和暗黑套装的体系设计]]

案例（做得对的）：
- AFK：英雄从 1 技能变 4 技能+专属武器——付费越多，同一个英雄的策略宽度越宽
- 原神：命座改变角色机制——看似同一个角色，策略宽度已完全不同
- 三战：体力绑定武将——更多武将 = 更多队伍 = 更多可同时进行的内容

反例：纯粹的"深度付费"——我比你快1点速度、装备比你多+1——这种竞争数值付费压缩而非拓展策略空间，让玩家疲惫，最终流失。

检验标准：设计付费时问自己"付费后游戏更好玩还是更无聊"，答案必须是前者。

参见：[[越付费，越好玩]]、[[魔灵召唤和暗黑套装的体系设计]]、[[付费颗粒度与体验闭环]]

### 4.3 设计付费的颗粒度、反馈与质变

**原则：商业化设计必须同时处理好三个层次——付费内容的"块大小"（颗粒度）、每次付费的即时回报感（反馈）、以及积累到阈值后的质变体验（二次曲线）。**

*依据：双曲贴现 → 即时反馈必需；线性累积让人疲惫 → 需要二次曲线连接短期反馈和长期留存。*

- **颗粒度**：角色=大块，宝石=小块——决定"多久能感受一次完整付费体验"
- **即时反馈**：每次付费必须产生立即可感知的回报
- **协同质变**：积累到阈值产生质变（2件套+2件套 > 4件散件）——玩家"越练越有动力"

参见：[[付费颗粒度与体验闭环]]

## 附三：原则关系图谱

```
元原则（怎么想）
    始于事实
        │
        ├── 找那条缝（方法：找到认知余量最大的结构点）
        │
        └── 区分骨架与血肉（诊断：区分结构与表面）
        │
        ▼
结构原则（怎么搭）
    以结构释放认知余量（总纲）
        │
        ├── 正交 ──→ 递进 ──→ 限制
        │    (子集：认知减负三种手段)
        │
        ├── 涌现
        │    (供需：余量需要去处)
        │
        └── 信息差
             (重叠：公开减负，隐藏博弈)
        │
        ▼
结构→体验映射（创造什么感受）
    认知余量 ─→ 顺势下潜的自在感
    正交 ─→ 可分解的掌控感
    递进 ─→ 层层深入的顿悟
    限制 ─→ 取舍的重量感
    涌现 ─→ 发现意外之喜
    信息差 ─→ 认知博弈的紧张
        │
        ▼
体验原则（怎么传递）
    让玩家发现，而非被告知（根基）
        │
        ├── 用节奏引导模式识别（核心机制）
        │     ├── 不均匀优于均匀
        │     ├── 对比而非堆积
        │     ├── 新内容互斥
        │     ├── 子波同相叠加
        │     └── 注意力调度
        │
    从场景出发，而非从能力出发
        │
        ▼
商业化原则（怎么变现）
    横纵双向设计
        │
    让付费接续玩法的深度弧线
        │
    设计颗粒度、反馈与质变
```

**跨层关键规律：**

- **正交性 + 递进式 = 涌现性的前提条件**（结构层内部的因果规律）
- **每条结构原则 → 一类特定的情感体验**（结构→体验映射层的核心规律——结构不是中性的，每种结构属性天然倾向于触发某种感受）
- **同一个结构 + 不同的传递节奏 = 不同的情感质地**（创造和传递不是串行工序——黑魂的战斗系统配上低惩罚=轻松挑战，配上高惩罚=压迫感）
- **让玩家发现（3.1）+ 节奏引导（3.2）= 可发现的乐趣**（体验层内部的协同机制——一个设目标，一个给手段）
- **让付费接续玩法的深度弧线（4.2）**：玩法拼图建立直觉层吸引力 → 数值条件作为同一玩法在逻辑层的深入 → 变现是这条弧线的副产品。付费拓展策略空间（4.2下半身）的前提是玩家已经沿弧线建立了"想完成玩法"的内在动机
- **横纵双向（4.1）× 让付费接续玩法的深度弧线（4.2）**：商业化维度的选择（横还是纵）决定了玩法拼图以什么形态展开，深度弧线决定了玩家沿什么路径进入付费。更深一层：4.2 弧线中逻辑层的数值量变，正是驱动 4.1 质变点从触发型走向突变型（乃至跨越到横向领地）的燃料——数值积累到临界点触发机制质变
- **找那条缝（1.2）⇄ 始于事实（1.1）**：找到缝的前提是看清事实中的结构
- **找那条缝（1.2）× 以结构释放认知余量（2.1）**：同一个机制，两种说法——1.2 是方法（去结构中找阻力最小的位置），2.1 是原理（那个位置之所以阻力最小，是因为结构在那里释放了最多的认知余量）。"十倍好玩"恰好是两者在游戏领域的交汇点：它既是设计师要找的最强缝，也是认知效率的极限
- **以结构释放认知余量（2.1）× 深度弧线（4.2）**：结构层通过正交、递进、限制等手段逐层降低认知成本——释放出的脑力是玩家沿弧线从直觉层滑入逻辑层再抵达变现层的动力来源。2.1 是结构层的认知引擎，4.2 是弧线的"怎么走"；两者共同解释：深度不是被推出来的，是被结构拉出来的
- **信息差即玩法 ⇄ 用限制创造策略**：信息不对称是限制的一种特殊形式
