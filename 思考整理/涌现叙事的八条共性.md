## 总览：四套方法，一个内核

四位设计师来自完全不同的起点——3A 叙事导演、独立模拟游戏制作人、实验叙事工作室创始人、大型商业模拟游戏创意总监——但他们的方法论在八个维度上高度趋同。

---

## 八条共性原则

### 一、玩家是共同作者，不是观众

| 来源 | 原话 |
|------|------|
| Levine | "玩家驱动的叙事"——叙事由玩家行为触发，不由创作者预设碰撞盒触发 |
| Sylvester | "《RimWorld》不是一个游戏，它是一个**故事生成器**"——游戏的存在不是为了讲故事 |
| Kennedy | 玩家把自己的人生经验带入 Glover & Glover，填补空白 |
| Brown | "这不是我们写的。**是你写的。**" |

**核心逻辑**：设计师的工作从"讲一个故事"转变为**"创造让故事涌现的条件"**。玩家不是被动的接收者，而是创作过程的合伙人。

### 二、留白 > 填满：用模糊性邀请投射

| 来源 | 做法 |
|------|------|
| Levine | 隐藏激情——不知道 NPC 的秘密动机是一种**资源**；揭示了才能利用 |
| Sylvester | 不画表情和肢体语言——"如果我们放入了画面，玩家就没法再想象了" |
| Kennedy | "能暗示就不模拟"；Glover & Glover 从不具体说明是什么公司；"把手指蜷曲成正确的形状。"——句号，不是"然后开始这一天" |
| Brown | Simlish、思想气泡、小便池随机选择——"说错比不说更糟" |

**核心逻辑**：模糊性不是设计的**缺陷**，而是设计的**工具**。它给玩家留出投射自己情感和理解的空间。一旦你替玩家填满了，你就剥夺了他们的创作权。

Sylvester 和 Kennedy 共享同一个关键词：**Apophenia**——人类大脑在空白中寻找模式的倾向。

### 三、系统碰撞 > 脚本编排

| 来源 | 做法 |
|------|------|
| Levine | 零和博弈的激情网络——弗兰克恨精灵 + 皮特信新神 → 帮弗兰克建神庙得罪皮特 |
| Sylvester | "许多系统交汇"——子系统之间的**意外交汇**产生故事 |
| Kennedy | 单个工作槽的双重含义（上班赚钱 vs 大功业）——**机制本身**讲了故事 |
| Brown | 故事树**并行评估**，数百棵树同时匹配小人的每一个行动 |

**核心逻辑**：故事不来自"第一步→第二步→第三步"的顺序编排，而来自**多个简单规则同时运行产生的冲突与交汇**。设计者的任务是设计规则，不是设计结果。

### 四、有限模拟，拒绝完美

| 来源 | 做法 |
|------|------|
| Levine | 每个角色只有 3 个激情——不做完整心理模型；"物理引擎"类比：从圆形矩形起步 |
| Sylvester | "角色 AI 不需要通过图灵测试"；"为了追求'伟大'而放弃'足够好'" |
| Kennedy | 疯狂砍——"复杂度预算"和"主题预算"；哀悼期法则 |
| Brown | "大A小I"——勉强算智能，极其人工。**没有机器学习，没有行为树，仓鼠在上班** |

**核心逻辑**：模拟得越少，反而越能产生有意义的涌现。过度模拟带来三个问题：开发成本爆炸、玩家认知过载、诠释空间消失。

这四条原则指向一个总纲：
> **设计师模拟的不是世界，而是"足够让故事发生的骨架"。**

### 五、非确定性 = 叙事资产

| 来源 | 做法 |
|------|------|
| Levine | "X 的 Y 次方种状态"；激情池——弗兰克有 10 套激情，每局随机抽 3 个 |
| Sylvester | 随机事件故意伤害玩得好的玩家；"不成比例的反击是戏剧的起点" |
| Brown | "雪花骗局"——几乎每个人都会经历第一次厨房火灾，但每个人觉得**那是自己的独特故事** |
| Kennedy | Roguelike 结构——短局时 + 不同起始条件，"前三次很棒" |

**核心逻辑**：随机性不是bug，是**feature**。它创造两种价值：
1. **可重玩性**——同一套系统产生完全不同的叙事
2. **个人化**——随机性 + 投射 = 玩家觉得"这是我的故事"

### 六、张力驱动，不让人人满意

| 来源 | 做法 |
|------|------|
| Levine | 零和博弈——你无法取悦所有人；红龙与银龙互相排斥 |
| Sylvester | 弹性失败——被打倒但游戏继续；劫掠者绑走角色后离开让你重建 |
| Kennedy | 工作 vs 魔法——**同一个槽**，只能选一个 |
| Brown | "搅乱战略格局"——等你嫁了老板后**换掉老板**；希望 vs 恐惧并行 |

**核心逻辑**：故事需要冲突，冲突需要张力。如果玩家可以让所有NPC都满意、所有系统都处于最优状态，就**没有故事了**。

Levine 最激进的表述：
> "我不认为'善恶'的选择是最有挑战性的。真正有趣的是——仅仅因为**你不做什么**，你对某些人就成了混蛋。"

### 七、系统透明，但交互结果深不可测

| 来源 | 做法 |
|------|------|
| Levine | 激情条和阈值线**全可见**；"好的时候叮一声，坏事的时候也叮" |
| Sylvester | 简单的 2D 符号系统，一眼可读；"画面是符号，不是拟真" |
| Kennedy | 卡牌全在桌面上——机制完全暴露；但游戏拒绝告诉你"怎么做" |
| Brown | 需求条可见，AI 逻辑可推理；"玩家几乎能立即理解小人的思维过程" |

**核心逻辑**：透明度降低认知负担，让玩家能做出**有意图的选择**。但简单的规则 × 复杂的交互 = 涌现的惊喜。如果你既不透明又复杂，玩家放弃；如果你透明但缺乏深度，玩家无聊。

**透明是信任的基础。意外是故事的燃料。两者缺一不可。**

### 八、内容模块化，跨上下文复用

| 来源 | 做法 |
|------|------|
| Levine | 激情、任务、角色可跨游戏、跨上下文复用；"我写得多，但写的东西可以重复使用" |
| Sylvester | "不可能的游戏设计"——玩家感知到开发者从未实现的东西 |
| Kennedy | 卡牌系统——每张卡出现在多种上下文中；"添加内容只需文字 + 行为 + 小图" |
| Brown | 故事树——同一节点被不同触发激活；"不添加新内容，用已有内容构建依赖树" |

**核心逻辑**：涌现叙事的**经济性**来自复用。一段对话、一个任务、一个性格特质——在固定脚本游戏中用一次，在涌现叙事系统中用一百次，每次在不同上下文里产生不同含义。

这是对"组合爆炸"问题的回答：不是少写，而是写的内容**可以重组**。

## 三条元原则

八条共性往上归类，凝聚为三条深层原则：

### 元原则 A：玩家是讲故事的人，不是听众

（统领 一、二、七）

所有设计决策指向同一个目标：**让玩家觉得故事是他们自己创造的。** 为此，系统必须：
- 响应玩家的行为而不是预定脚本（一）
- 留出空白让玩家填充（二）  
- 足够透明让玩家做出有意图的选择（七）

### 元原则 B：为碰撞设计，不为序列设计

（统领 三、五、六、八）

不写故事线，写**会碰撞的零件**：
- 多条规则同时运行（三）
- 随机性打破最优路径（五）
- 零和/张力让碰撞有后果（六）
- 模块化让碰撞可以发生在任意上下文中（八）

### 元原则 C：更少的模拟 = 更多的意义

（统领 四、二）

这四条共享一个反直觉信念：**追求完整模拟不仅昂贵，而且适得其反。** 因为：
- 完整模拟消灭了留白，消灭了玩家的投射空间（二）
- 完整模拟产生了大量与叙事无关的噪音（四）
- 完整模拟让系统变得不透明、不可理解（七）

## 四篇文章的定位

```
       深度模拟
          ↑
    Sims  │  RimWorld
   ───────┼───────→ 玩家诠释空间
 Cultist  │  Levine
    Sim   │
          ↓
       手写叙事
```

- **The Sims**：最重的模拟 + 最强的抽象化（Simlish）——在矛盾中取得平衡
- **RimWorld**：深度模拟 + 刻意拒绝"公平"——用系统不完美催生故事
- **Cultist Simulator**：最少模拟 + 最强玩家投射——Apophenia 的极致实验
- **Ken Levine 愿景**：系统性叙事结构的理论蓝图——还没有实现，但定义了方向
